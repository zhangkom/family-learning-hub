# 双宝名校计划

一个面向两个孩子的家庭学习网页：大宝（高中二年级）与小宝（初中一年级）各有专属页面，共用“目标—诊断—练习—错题回炉—周复盘”的学习闭环。

## V2 学习工作台

- 家庭总览：两个孩子的阶段目标与每周家庭共学节奏
- 大宝页：广东高中课程、“3+1+2”、中大投档位次坐标与高中倒推路线
- 小宝页：深圳新中考 630 分结构、各学科重点与初中三年路线
- 小宝每日难点：数学、英语一日一难点，答错自动收入错题本并生成变式入口
- 大宝每周复盘：数学、物理、化学、生物扫描入口、出处字段、讲透流程和历史回看
- 答题判定、错题记录和第 2/7/30 天复习规则已有自动化测试
- 学科地图、错题生命周期、考试规则与官方来源

完整的产品方案见 [docs/初步方案.md](docs/初步方案.md)，课程难点依据与标签见 [docs/课程难点地图.md](docs/课程难点地图.md)，数据与跨设备设计见 [docs/数据与跨设备方案.md](docs/数据与跨设备方案.md)。

## 本地运行

```powershell
npm run dev
```

打开 `http://localhost:3000`。

运行验证：

```powershell
npm test
npm run build
```

## 两台电脑协作

腾讯云访问地址： https://123.207.232.151/family-learning/ 。部署、更新与回退见 [腾讯云部署](docs/腾讯云部署.md)。

源码仓库为 `https://github.com/zhangkom/family-learning-hub`。新电脑首次执行：

```powershell
git clone https://github.com/zhangkom/family-learning-hub.git
cd family-learning-hub
npm install
```

之后开始工作前执行 `git pull --ff-only`，结束工作后提交并 `git push`。孩子的扫描件、答案和成绩不进入 Git。目前公开版的错题和进度仅保存在当前浏览器，扫描上传与跨设备同步尚未开放。仓库当前在 GitHub 上是 Public，建议在开始录入真实家庭配置前改为 Private。

## 重要说明

当前按“大宝 2028 届、小宝 2029 中考”建模，需按实际学籍确认。招生政策、专业选考要求和投档位次每年都会变化，应在每年 7—9 月使用官方数据更新。
