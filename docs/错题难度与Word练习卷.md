# 错题难度与Word练习卷

## 题卡与难度

题卡顶部显示实际试卷名称、科目和原题号；列表顺序编号与原题号分开。知识点和原图在同一道题卡内切换，知识点正文随客户端保存，避免点击时等待模型请求。

每题难度为1至5星，未评级按3星显示。用户点星保存，失败明确提示；评分与题目、学生绑定。保存记录区分用户、AI及默认来源。后续AI建议不得覆盖用户手动评分；重新识别、旧客户端回写和修订题图亦须保留手动评分。

## 练习卷内容

- 默认只输出已核对的题目、完整条件与配图，去除作答和批改痕迹，留答题空间。参考答案与解析为明确勾选的附录，未核对不能用定位摘要或模型草稿代替。
- 数学结构使用Word原生OMML公式：分式、上下标、左上下标、根式、矩阵等可继续编辑。物理量及变量按语义斜体，单位和化学元素符号正体；汉字条件保留完整，不能在字体回退时消失。
- 原题图可依据核对后的线条和标注重绘；图像条件必须忠于原件，不能按推测答案改图。受控原图裁片仅从当前学生的已授权题图版本取图，不接受任意路径或外部URL。
- 题目前标明实际来源与原题号，显示当前难度。A4纸张，页眉显示学生与练习卷名称，页脚显示页码与总页数。
- 一般单题的题干、图表和答题位置保持同页；剩余空间不足整体移至下一页。长于一页的阅读材料或共用实验条件单独列为共用材料，题目前给出材料页码，不以缩小至不可读的方式硬塞一页。

## 导出与版本关联

从错题本当前科目筛选进入Word导出，初始选中当前列表并保留顺序。预检逐题列出可导出数量和阻断原因；所有选中题就绪后才生成。不静默跳过缺题，用户可明确取消勾选或选择仅导出就绪题。

打印稿与来源内容指纹绑定；题干、图框、原题号或图像版本改变后需要重新核对。单独调整星级或收录状态不使内容核对失效。导出期间若题目被改动、删除或移到其他学生，旧结果不交付。

手机用系统文件保存界面选位置，下载核对类型、大小和SHA-256；取消保存能重试。退出、换学生或超时取消旧请求。浏览器下载不等于Android文件保存流程已真机验收。

## 核对与运行约束

内容准备先核对原题、公式、配图与来源，再实际生成Word、渲染、逐页检查。源文件和真实学生资料只在工程私有目录保存，不能打包入APK或公开下载目录。批量回写先在一致性备份副本验证，校验每道题的ID、学生、源图哈希、来源版本与准备内容哈希，逐项保存回执；版本冲突必须停止，不能覆盖并发编辑。

排版核对不代表解题正确性核对；错题收录标记不代表学生独立作答成绩。新增答案须按电脑集中复核流程独立核对，实际能力分析仍只引用可核对的练习证据。
