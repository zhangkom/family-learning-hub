# 0.3.2 分析进度与人工核对

版本 0.3.2 / code14，沿用长期签名及既有增量更新协议。

## 本版行为

分析中显示真实排队、处理中、等待重试、中断待恢复及服务暂停状态，显示提交后经过的时间和当前尝试次数。时间不代表剩余耗时，不虚构百分比。仍采用现有队列、三次尝试和模型参数。

每份单题分析可以标记“核对无误”，或记录“题干识别有误”“答案或推导有问题”“题图或条件不完整”。题干识别问题需填写完整修正题干；另外两类需填写具体说明。保存意见不调用模型。点击“按校对内容重新分析”才入队，将当前题干及具体意见作为待核对材料交给模型，要求独立复核。用户意见不被视为数学正确性的证明。

原始 AI 结果保留，用户意见另存并绑定具体结果生成时间。改正共用题干后，关联子题的分析一并标记过期。重试或失败保留上一份结果供对照；新结果生成后清除上一份结果的核对标记，必须重新核对。人工核对标记不等于孩子掌握程度，也不代替原有题框、作答作者的确认。

后台核对接口校验家庭归属、资料 revision、结果生成时间、字段白名单和活动任务，拒绝过期提交、跨家庭访问、分析中的修改及对过期分析直接确认。普通校对接口不能伪造服务器核对字段。没有新增数据库表结构迁移，记录随 scan_versions 保存。

延续 0.3.1 的云盘每组200张与本机题图读取，并修复状态轮询反复读取、解码同一张本地照片的开销。云端 AI 仍需网络。此版未调整模型、画质、超时或推理参数，也未宣称识别准确率或模型响应速度提升。

## 已验证与边界

Windows 后台175项测试、TypeScript、指定范围lint、自托管构建；客户端157项测试、lint、构建通过。新增覆盖家庭隔离、过期版本、结果绑定、人工字段防伪、父子题过期、真实队列状态、重试保留结果及修正上下文。

真实隔离 HTTP 后台与浏览器合成原生桥联调完成：存错题并分析 → 核对 → 改正题干 → 保存 → 刷新并重新打开 → 按校对内容重新分析 → 核对新结果。两次请求使用本地合成模型响应，保存意见不增加调用；重分析等待期间旧结果保留，修正题干进入模型请求，新结果重置核对标记。分析刷新不重复读取照片，服务器题图下载为0，320像素窄屏无横向溢出。证据在 `work/qa-032/analysis/`。

正式环境只读检查发现3条历史已完成单题任务，但没有可用分析耗时审计，尚不能归因用户所述“慢”或判断真实题目准确率。此次不读取私人原片、不调用收费模型、不创建生产测试资料。下一步以用户实际题目和新产生的耗时审计核实识别及推理问题，再决定参数或模型优化；之后推进分步提示、相似题练习和复测。

物理 Android 设备的显示、私有文件性能和覆盖/增量安装待真机验收。浏览器合成题仅验证流程，不是识别质量或数学质量评测。

## 发布与回退

先在 Linux 独立目录完成同一源码的后台检查，停止写入并备份数据/配置，验证恢复副本后切换运行版本；原件和所有业务表逐行核对。发布完整APK和最多四条适用差异包，最后独立公网下载验证签名、SHA和正式Java逐字节还原。

回退只能切换运行代码，保留最新数据库、原件和版本记录，不能用旧快照覆盖新增资料。旧客户端仍可使用原有分析；0.3.2在旧后台会明确提示升级后再保存核对。旧后台不理解人工意见，回退期间不应继续基于新意见重新分析，应恢复0.3.2或前向修复后再处理；此前意见仍可从版本记录审计。
