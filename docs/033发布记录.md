# 0.3.3 保留原文件名、按范围选图

版本0.3.3/code15，沿用长期签名与原有增量升级协议。

## 本版行为

云盘新导入图片从Android内容提供者的DISPLAY_NAME读取原文件名，随本机私有原片记录持久保存，上传队列、云盘清单和下载使用该名称。大小写、中文、空格及正常长文件名保留；控制字符、路径分隔符等不安全显示字符仍规范化。服务器原件继续使用独立ID保存，不按用户文件名拼接存储路径；同名不同图不会覆盖，也不单靠名称判断已上传。上传回执、字节数与SHA校验维持原协议。

旧版已经导入的记录没有保存来源文件名，无法凭UUID准确还原，保留旧记录和原件，不猜造名称。需要原名时从原相册重新选取；这会创建新的选图记录，并不自动给旧云图改名或合并同名照片。

拍题收集页改为“已选 X 张”，移除100张选择、恢复、按钮禁用和上传截断。可继续添加，上传内部每200张顺序处理。图片云盘原有超200张自动拆组保持。单张格式、像素和大小校验仍适用；一次只读取一张原片。

Android的拍题收集页与图片云盘均新增“按文件夹选范围 / 全选”。通过系统文件夹选择器授权照片所在文件夹，只列出其直接包含的JPEG、PNG、WebP图片，不递归扫描子目录。按文件名升序固定顺序，用起始图片和结束图片指定连续范围，包含两端；也可全选。确认之前只读取文件目录信息，之后逐张复制到应用私有目录，不直接上传或修改相册。

文件夹授权引用与选图批次一同保存；导入完成或取消后，仅在没有其他待处理批次引用时释放读取授权。进程中断后从“恢复上次选图”继续；如果中断发生于范围确认前，可以忽略未完成选图后重选。原片不随批次清理删除。

系统目录支持依据 [Android Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files)。Android会限制部分目录的选择，可选DCIM/Camera等实际照片子目录；应用不申请整个相册/存储的读取权限。此功能为按文件名的起止选择，不宣称已实现相册内拖动矩形框选。

## 验证与边界

后台176项测试包含长原名、同名不同图片和原字节下载；客户端159项测试包含450张拍题选择、范围参数、按原名入队与重启恢复。Java纯逻辑13项测试覆盖名称、稳定排序、起止边界和450张全选；原有39项批次/文件系统/HTTP测试保留。Android原生代码编译检查通过。

浏览器验证覆盖205张一次选择后继续添加5张，完整210张顺序上传、丢回执恢复及同ID重试；320像素窄屏只显示计数。真实隔离HTTP云盘验证450张200/200/50分组，原名列表/下载和重启续传；合成Android桥覆盖文件夹模式接线、原名持久化及实际上传回执。具体通过结果与截图在 `work/qa-033/`。

合成原生桥不能代替实际Android系统文件夹选择器和原生范围对话框验收。文件夹授权、系统返回、长列表选择与覆盖/增量安装仍待真机验证。没有真实作业读取、生产测试资料或收费模型调用。

## 发布

后台仅改变云盘原文件名的显示清理策略，没有数据库结构迁移。仍先一致性备份、恢复验证再切换；回退只换代码，保留当前数据、原件及版本记录。完整APK和适用的最多四条补丁经签名、SHA、正式Java逐字节重建及公网下载复核后交付。
