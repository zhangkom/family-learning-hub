# 原页单题与练习题的存储设计

2026年10月3日，根据用户对原图归档、题目溯源和完整配图的要求制定。本文是后续数据与界面开发约定，末尾区分现有能力与待实现内容，不能把设计字段当成已经上线的数据。

每道题必须能回到来源页和具体位置。原件、带笔迹的单题截图、适合再次做题的整理版分开保存和管理；三者共用稳定的来源关系。文字中的“如图所示”必须有对应的真实图，配图说明不能代替配图。

## 原图与资料分类

一次上传是一批文件，不等于一张试卷，也不等于一个科目。批量导入允许包含不同学科、学习阶段和资料类型，上传数量不设应用层上限。先保存每张照片，后做分类；不能要求用户按科目反复上传。

浏览层级采用“学生 → 学年及学期 → 科目 → 资料 → 页”。另提供资料类型、上传日期筛选。示例：大宝 → 2025至2026学年下学期 → 物理 → 第三单元测试 → 第2页。暑假作业记录其实际所属学年和暑假阶段，不根据当前年级或上传时间推断。该示例不代表现有照片已确认的真实分类。

| 对象 | 必须保存的信息 | 约束 |
| --- | --- | --- |
| 原件 | 稳定原件编号、家庭和学生、原文件名、原始字节校验值、格式、像素尺寸、上传时间 | 不覆盖或重新编码原件；同名不等于同一图片 |
| 资料 | 稳定资料编号、标题、学年、当时年级、阶段、科目、资料类型 | 阶段含上学期、下学期、寒假、暑假及待确认；类型含单元测试、期中、期末、日常练习、假期作业、其他 |
| 资料页 | 稳定页编号、所属资料、展示页序、纸面页码、原件引用 | 展示页序与纸面页码分开；不将文件名顺序当成已核对页码 |
| 分类判断 | 建议值、判断依据、待确认或已确认、修改者和修订号 | AI 只提出建议，无法判断时进入待整理；用户可批量确认和修改 |

资料标题不要求唯一，同一份试卷的多张照片通过资料编号关联。重复拍摄同一页保留为不同原件，用户选择使用哪个版本，不能悄悄覆盖。混合学科的一份资料允许标记“综合”，题目仍逐题记录科目；一张照片拍到两份资料时保留页区域分别引用，不能强行合并成一张卷子。

资料分类改变只修改元数据，不移动或改名原件。学生归属变更是单独操作，须验证家庭内归属并清理旧学生界面的图像引用，不能顺便由自动分类完成。历史资料缺失的字段标为待确认，保留旧记录，不按现任年级或默认孩子回填。

现有服务器原件路径保持不变：扫描为 `data/<owner hash>/scans/<scanId>/original`，云盘为 `data/<account hash>/cloud-photos/<photoId>/original`。新增资料和页关系存数据库。新目录遵守工程目录约定，原件不进入公开 APK、模型日志或临时清理范围。

## 单题截图与来源链

完整来源链为“原件 → 资料页 → 框题所用的处理图版本 → 题目 → 区域”。整理题、错题收录、讲解和练习都引用同一题目编号。再次收录不重复建立一道题。

从云盘或本机导入时还须记录明确的云盘原件编号及不可变版本、本机原片编号和源校验值，连接现有云盘与扫描两个存储体系。关联只能基于经校验的内容身份，不能仅凭同名或相近上传时间补关系。处理图上传成功不代表相机原片已经云端备份；来源关系缺失时保留待核对状态。

每题分别记录大题号、小题号和必要的父题关系。例如“第三大题 → 第12题 → 第2小问”，不能只保存列表里的第5个位置。照片中的题号未知时写待确认，列表序号不当成原题号。题目可跨页；共用材料、图表和父题干通过明确引用关联，不能把相邻题整个包进一个大矩形。

每个题干、配图、作答和批改区域保存稳定区域编号、来源页、处理图版本、坐标空间及框选坐标。坐标使用已摆正处理图的归一化边界，同时保存原始尺寸、EXIF 方向和原图与处理图之间的变换。再次旋转或透视处理必须生成新版本，不能让旧坐标直接套在新图上。

单题截图保存两部分：

1. 权威裁剪记录：原件和处理图的校验值、关联页与题目、区域坐标、区域类型、修订号。这是可重建截图的依据，永久保留。
2. 派生图片：按区域实际裁剪的图片及展示预览，关联上述修订号和校验值。多区域分别保存并按阅读顺序组合，原题截图保留笔迹和批改证据；整理版只引用题干和配图。框选修改生成新修订，旧记录保留。

长期保留的派生题图放在项目私有 `data/` 中独立的派生资源目录，纳入备份和引用检查；转换过程的中间文件在 `temp/`。本机保存在应用私有持久目录或私有 WebView 数据库，隔离服务、家庭、学生、原页。临时缓存文件不作为题目唯一副本。删除相册照片或清理预览缓存不应删除已收录题目；删除原件前必须检查所有资料页、题目和练习引用。

题目卡上的“原图”切换为该题已框出的局部原图，不是打开整张照片。题目来源可展开查看资料、页码和题号，再进入整页定位并高亮对应区域。原文件名用于帮助核对，不用来充当关联主键。

## 完整的整理题

整理版按试卷阅读方式组合题号、公共条件、题干、小问、选项、表格、原题配图及必要答题空间。公式需保留数学结构，图中的字母、刻度、单位和图注不能丢失。优先保存原图裁出的真实图，不凭文字重新画一个可能不一致的示意图。

配图已单独标记时，整理后的题干和选项配合真实图显示。配图尚未分离或文字转写未核对时，使用完整单题截图作为保底显示；不能只留“如图所示”，也不应重复堆放一遍识别文字和同一题截图。截图属于原貌展示，含学生笔迹时不能称为干净练习版。

原题、学生原作答、教师订正、AI 参考答案分别存储。擦除笔迹可能损伤原图条件，不能默认自动擦除并当作已核对题目。难题和错题的标记规则沿用 [错题与重点题目收录标准](错题与重点题目收录标准.md)，分类记录不写进可打印的题干或选项中。

整理题需有可核对的完整性状态：缺题干、缺图、缺公共条件、低清待核对、已核对。模型提取“如图”等提示可以发现缺图嫌疑，但不能仅凭没有这些词就断定是纯文字题。人工确认至少核对文字条件、公式、选项、配图、父题和小问关系；修改以上任何内容会使旧确认失效。

## 下载与打印约定

未来下载和打印复用同一份完整整理题，不另建一套仅含文字的导出逻辑。习题与答案分开，按 A4 页面分页，题干、关联图和选项尽量放在一起，跨页时有明确续题标识；图像保留比例，低清晰度提示重拍或补图，不能用拉伸伪装高分辨率。

缺图、缺条件或未核对的题不能标为完整可打印练习。用户可回看或导出原貌题图，但应标明含原作答、未整理。导出文件保留私有来源索引或题号映射，方便核对；公开分享须另有用户授权。

## 本机优先和恢复

正常拍题后，分析、框选和预览优先读取手机保存的原片或精确处理图；云盘上传只作备份，不能强制走上传后再次下载的循环。云端 AI 服务仍需提交分析所需的图片数据，不能将本机读图称为离线 AI。

历史题、其他设备建的题或本机副本丢失时，明确提示缺少本地图。用户点击“恢复题图到本机”后，下载精确原页一次，核对文件、实际解码并持久保存，再供该页所有单题按坐标共用。失败或空间不足继续显示可恢复状态；成功重开应用后不应再次下载。切换家庭或学生不能看到之前的图像。清除应用数据或卸载后的恢复仍需联网。
