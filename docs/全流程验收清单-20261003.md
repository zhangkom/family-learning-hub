# 知识棱镜AI全流程验收清单（2026-10-03）

本次范围：管理员后台、电脑Codex集中复核，以及现有App各模块的连续使用流程。Android版本仍为0.3.10/code22；本次功能在服务端和电脑工具中交付，客户端业务源码未改变。管理员操作指南见 [管理员与电脑集中复核](管理员与电脑集中复核.md)。

“通过”必须连同验证方式阅读：本次浏览器和隔离后端测试采用合成照片，原生相机、相册、存储与安装使用模拟桥；学习模型采用明确标记的固定测试响应，不代表真机或真实模型准确率。没有将测试题、测试成绩或复核答案写入正式学生资料。

## 检查中卡住的地方及处理

1. 首次SSH握手失败：重连后完成Linux构建，期间继续本地回归；未据连接失败重置线上服务。
2. 两个旧浏览器脚本遗漏新增学习历史接口，模拟返回错误或中止请求：补齐空学习记录后重跑通过。
3. 旧按钮“拍照收题/相册选图”和旧“题目页资料列表”已变更：测试改走现有“录错题/批量错题上传/首页原题照片”的真实路径，注册及解析核对重跑通过。
4. 能力图谱测试依赖题卡暂时的OCR文字，题图加载后文字被完整截图替换：改用稳定的来源照片核对排序，并验证证据回看的真实题干与练习来源，重跑通过。
5. 210张上传的20秒固定等待不足：截图确认任务仍在继续，延长整批验收等待后完整通过。没有修改上传上限或隐藏失败。
6. 快速合成工作进程可能在两次轮询间完成，旧脚本硬等短暂“模型正在分析”：改为验证已入队/分析中的真实任务状态、旧结果保留和最终新结果，不要求某个瞬时提示必然被看到，重跑通过。
7. 相机失败恢复区现位于首页折叠区域：展开后重试、移除引用和本机原片均通过；异常发生时主动展开/醒目提示作为后续体验改进，不把“折叠中看不到”误报为缓存资料丢失。
8. 正式主机admin初始化受私有父目录权限阻挡：使用与正式服务一致的systemd私有挂载执行后创建成功，未放宽目录权限。公网真实网页已验证登录、首次改密门禁、退出、管理接口拒绝未登录和390/1280布局。

以上后续修改只涉及验收脚本，不改动已发布Android业务代码。Windows后端280项、客户端212项自动测试，以及对应类型检查、范围lint和生产构建通过；Linux同套后端检查通过。UI自动化含13个App场景和管理员独立场景，证据存于工程私有 `work/qa-admin/`。
