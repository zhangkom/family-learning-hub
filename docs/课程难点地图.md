# 深圳课程难点地图（V2）

更新时间：2026-08-31

这份地图用于给错题贴标签和安排家庭复盘，不是官方发布的“难度排行榜”。难点由国家课程标准、深圳考试改革要求中的基础性、综合性、应用性、探究性和开放性任务倒推得到。学校实际教材版本、学期和章节要作为可配置项，不能在未确认前猜测。

## 小宝：初一每日学习

### 数学

| 难点簇 | 常见卡点 | 每日练法 |
| --- | --- | --- |
| 有理数与符号 | 正负、绝对值、数轴方向混淆 | 文字、数轴、算式三种表达互译 |
| 代数式与整式 | 字母意义不清、去括号与合并同类项 | 每次只练一个变形依据，并口述理由 |
| 方程与实际问题 | 读不出等量关系 | 先圈未知量和关系句，再列式 |
| 几何图形与表达 | 看图凭感觉、步骤缺依据 | 画图—标条件—写依据三步固定化 |
| 数据与概率 | 会算不会解释数据 | 用一句话说明结论如何由数据支持 |

### 英语

| 难点簇 | 常见卡点 | 每日练法 |
| --- | --- | --- |
| 语音与听辨 | 看得懂但听不出 | 短句听辨、跟读、复述形成闭环 |
| 词汇语境 | 只背中文释义 | 在句子和主题中复现词义与搭配 |
| 主谓与时态 | 第三人称单数、时态标志遗漏 | 先圈主语和时间，再决定动词形式 |
| 阅读理解 | 只找原词，不会信息整合和推断 | 标证据句并说明答案依据 |
| 写作表达 | 句子碎、组织弱、错误反复 | 每日改好 1–2 句，每周完成一个短段落 |

小宝页面当前只开放数学和英语；语文、物理、化学、生物、历史、道法、地理等保留扩展位。每天只做“理解一个点—针对题—错题记录—一道变式—反讲”这一条短闭环。

## 大宝：高二每周复盘

| 学科 | 重点难点簇 | 复盘证据 |
| --- | --- | --- |
| 数学 | 函数与导数、数列与不等式、向量与几何、解析几何、概率统计、建模与规范证明 | 条件翻译、关键转折、运算检查、结论表达 |
| 物理 | 模型选择与受力、运动图像、能量与动量、电磁场与电路、实验数据与不确定性、多过程综合 | 对象与过程、受力图/过程图、定律适用条件、单位与方向 |
| 化学 | 宏观—微观—符号转换、物质的量、反应原理与平衡、电化学、实验设计与证据、有机结构转化 | 粒子/方程式、变量控制、实验现象、证据链和规范术语 |
| 生物 | 结构与功能、代谢与能量、遗传与概率、稳态调节、生态与进化、实验变量与图表 | 概念边界、自变量/因变量、数据趋势、结论是否超出证据 |

每一道高中错题必须保留：原始扫描件、学科、章节/知识点、孩子原答案、标准解答、错因、一道变式、来源、录入时间和复习状态。物理受力图、函数图像、化学装置/微粒图、生物过程图按孩子追问动态补充。
