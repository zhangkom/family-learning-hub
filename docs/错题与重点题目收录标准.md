# 知识棱镜AI 错题与重点题目收录标准

版本：1.0。用户确认日期：2026年10月3日，北京时间。

本文规定拍摄或导入试卷、练习照片后，如何根据纸面作答和批改标记识别错题、难题及重点题，作为后续开发、模型提示、界面展示和验收的共同依据。用户已确认前五张云盘照片的截图判断，并明确同意将“红笔直接补写答案”和“多选题只划掉一个选项”纳入错题规则。

这是已确认的产品标准；记录标准不代表当前发布的 App 已实现或通过全部自动识别验收。

## 一 收录规则

| 编号 | 可见情况 | 分类及收录结果 |
| --- | --- | --- |
| R01 | 黑笔或铅笔原答案被红笔划掉，旁边用红笔写出新答案 | 判为错题，收录。保留原答案、划改痕迹及订正答案。 |
| R02 | 填空、文字答案或解题过程中的部分内容被红笔订正 | 判为错题，收录；不局限于选择题。 |
| R03 | 作答位置直接用红笔补写答案，没有可辨认的黑笔或铅笔原答案 | 按用户确认的约定判为错题，收录；原作答记录为“未见可辨认原答案”，不能补造。 |
| R04 | 原答案中的错误部分被红笔明确删去，例如多选答案中的一个选项被划掉 | 判为错题，收录；不要求旁边另写一组红色答案。原选项读不清时保留待确认标记。 |
| R05 | 有可辨认的黑笔或铅笔作答，未发现红笔否定、替换或订正答案 | 按本规则视为正确题，不因作答本身自动收入错题；若另有重点标记，仍按重点题收录。 |
| R06 | 题号前有手写红色五星标记，如五角星或星号式重点标记 | 作为难题／重点题收录，不要求这道题做错。 |
| R07 | 题号前有手写红色三角标记 | 作为难题／重点题收录，不要求这道题做错。 |
| R08 | 同一道题既符合错题规则，又有红色五星或三角标记 | 同时保留“错题”和“难题／重点题”属性，保存同一题目，不重复创建两道题。 |
| R09 | 未作答，或答案、颜色、划改关系、题目归属看不清 | 标为待确认；不能仅因“没有看到红笔改答”而判为正确。 |

“难题／重点题”在本文指同一类主动收集的重点复习题，不另行推断统一难度等级或能力分数。

## 二 判断边界

先判断笔迹属于哪一道题、位于题号还是作答位置，再判断标记含义。红色五星和三角必须是与该题题号关联的手写重点标记；印刷图形、几何题中的三角形、公式符号及其他题的批注不能套用 R06、R07。

红色勾号、圈画、下划线、箭头或普通解释文字，本身不表示原答案错误。只有符合上表中“改答、补答、否定或删去答案”的情况，才据此判为错题。识别到红色并不等于识别到订正。

原答案、批改动作和订正答案分别记录。不能用订正答案覆盖原作答，也不能因最终答案已经订正正确而取消原来的错题属性。仅凭颜色不认定作者是老师、家长还是学生；作者未知可保留，收录依据写明为本标准约定的批改标记。

“按标记视为正确”是收录分类，不等于 AI 已独立验算正确，也不证明学生已掌握。纸面收录结果不得冒充一次新的独立练习或复测成绩，不直接生成能力分数。后续独立验算或用户校对发现冲突时，应展示冲突依据并允许修正。

## 三 自动框题和图片保留

1. 按原卷阅读顺序逐题定位，保留原题号、小问和共享题干，不因整张照片存在红笔就把所有题判为错题。
2. 用于判断的范围须包含题号前的标记、原作答及其订正，避免先裁掉星号、三角或旁边的新答案再进行分类。
3. 正式题图须完整保留题干、条件、选项、表格及原题配图。配图与相邻题目在版面上交错时，可按多个关联区域保存，不能混入别题后当成同一题的条件。
4. 小问出错时记录具体小问，同时关联必要的父题题干和配图。核对答案局部的截图不能替代完整题目。
5. 题目跨页、内容截断或题框归属不清时标为待确认，不补造缺失条件。
6. 保留来源照片、题框位置与识别依据。原件及原文件名保持不变；分析和预览沿用本机原片或处理副本优先的约定，云盘用于原件留存。

## 四 收录及人工修正规则

清晰符合 R01 至 R04 的题目进入错题收录；清晰符合 R06、R07 的题目进入重点题收录。没有错误依据、也没有重点标记的正确题不自动收录，但原照片保留，用户仍可主动选题收录。

识别结果应让用户看到“分类、理由、对应原图区域”。可用理由包括“原答案被红笔改写”“红笔补答”“多选项被划掉”“题号前红色星号”“题号前红色三角”。结果模糊时给出具体待确认项，不能展示成已确定的正确或错误。

错题属性和重点题属性分别保存、分别修改。用户可以调整题框、改分类、补充原答案或订正答案；重新识别不能悄悄覆盖已经人工确认的结果。同一来源题重复识别或重试时，应更新关联结果或提示复核，避免重复收录。

## 五 已确认样例和验收清单

2026年10月3日，按云盘当时显示顺序检查前五张照片，用户已确认以下判断：

| 样例 | 用户确认的结果 |
| --- | --- |
| 第1张，化学选择题原选项被红笔划去并写出新选项 | 错题，符合 R01。 |
| 第2张，语文文字答案中有红笔纠正并重写 | 错题，符合 R02。 |
| 第2张，语文作答位置直接出现红笔补答 | 错题，符合 R03。 |
| 第3张，物理选择题只有铅笔答案，未见红笔改答 | 按标记视为正确，符合 R05。 |
| 第4张，物理多选题中一个选项被红笔划掉 | 错题，符合 R04；无需另写红色替换答案。 |
| 第5张，物理解答题保留铅笔过程，未见红笔订正 | 按标记视为正确，符合 R05。 |

这五张中没有找到题号前明确的红色五星或三角。R06、R07 已由用户指定，但其真实图片识别效果仍需用对应样例验证，不能声称本次已经验证。

真实原图、截图和题干留在家庭资料与私有核对目录，不嵌入源码、公开文档、APK 或合成测试资源。本文仅保存规则及概括后的样例。

后续验收至少包括：

- 一张含多道题的照片逐题分类，某题的红笔订正不得影响相邻题。
- 选择题改选项、文字局部订正、红笔补答、多选删项分别识别正确。
- 红色星号和三角与题号正确关联，正确但有重点标记的题也能收录。
- 同时为错题及重点题时保留两个属性，题目不重复。
- 红勾、普通划线、箭头、印刷图形不误判为错题或重点题。
- 未作答、模糊、遮挡、跨页等情况进入待确认，不强行判正确。
- 题干、配图、选项和批改证据完整保留，人工修正及重复识别不丢失已确认结果。
- 收录分类不写入独立作答成绩，不据此伪造能力分数。

后续规则变更应注明用户确认日期并更新本文；本文件是错题及重点题自动收录规则的统一入口。
