## 修复与显示调整

本次只读核对发现，用户反馈的八道错题关联六张扫描图片，服务器原件全部存在，但扫描记录没有可供手机直接读取的本机处理照片身份。此前桌面端真实资料验收使用本地拦截，不能证明实际手机能够关联这些图片；本次以缺少该字段的历史记录复现并补齐恢复流程。

正常本机照片继续从应用私有目录读取。缺少本机关联的题图，由用户点击“恢复题图到本机”，下载一次后校验文件大小、格式和 SHA-256，并实际解码、事务保存到私有 WebView 数据库。同一来源页的多道题及详情共用该副本，退出重开后读取本机。普通重试不发起下载；保存失败、损坏和取消不当作成功。跨家庭、学生、服务隔离，卸载或清除数据后需重新恢复。

已确认文字且有独立配图框时，题卡展示题干、分开的 A 至 D 选项及原图真实配图。文字未确认或图尚未分离时显示完整单题截图，不丢图也不重复堆放文字。原图按钮继续在题卡内切换题框；来源信息可展开查看原文件名、题号、科目和来源说明。题图未就绪或公共条件关联缺失时明确提示内容不完整。

三层图片的后续约定见 [原页单题与练习题的存储设计](原页单题与练习题的存储设计.md)。按学年学期与试卷分类、跨页关联、结构化大题及小问、持久单题派生文件和打印仍待开发。本次未改写生产题目、分类或原图，后台继续运行已验证的 0.3.8 服务。

## 验证范围

客户端 207 项测试、TypeScript、客户端范围 lint、生产构建及 Android 签名构建通过。现有 Vite 动态导入提示和 Gradle 弃用提示保留，不影响本次构建通过，不宣称全仓库通用 UI lint 通过。

浏览器合成原生桥与真实 IndexedDB 验证了历史图片恢复、重开持久保存、题卡与详情共用、存储写入失败及重试、同大小文件损坏检测、取消、归属隔离、无自动下载、无 IntersectionObserver 回退、本机处理工作繁忙重试。320、390、768 宽度无横向溢出，原题和配图裁剪比例正确。题目、详情、学习与能力图谱之间的往返及账号和学生切换检查通过。测试没有调用真实模型，没有写入真实学习记录。

没有连接 Android 真机；浏览器原生桥不能替代实际手机的持久存储、覆盖安装和桌面主题验收。
