# 0.3.4 相册起止范围与页面布局

版本0.3.4/code16。客户端改进相册范围、收题与学习页面布局，后台新增学生统计读取接口，数据库结构不变。

## 相册范围

图片云盘的“相册选择”打开应用内本机相册缩略图页。点第一张，向任意方向滚动后点最后一张，包含两端的整段图片按当前显示顺序选中；向前、向后选择都支持。可继续选另一段，重叠部分不重复；“逐张调整”可取消个别图片，再切回范围模式；也可以全选或清空。

显示顺序为照片拍摄时间由新到旧，缺少拍摄时间使用加入相册时间，相同时间以媒体编号稳定排序。可切换系统相册分类；切换分类清空当前选择。范围基于该次显示的目录快照，滚动不会重新排序。回到前台重新查询权限和照片；目录顺序或授权内容改变时清空范围并提示，避免误选。旋转/系统重建时只恢复与当前快照一致的选择。

照片目录在后台读取，缩略图按可见格子加载，有缓存和有界工作队列，不同时解码整段原图。确认之前只在手机展示授权照片，不上传。确认后将所选URI按显示顺序保存到原有持久批次，再逐张导入本机私有原片目录，沿用原文件名和每200张上传分组。通过私有批次传递大量选择，避免把成千上万URI塞入Activity结果。导入后原有本机分析流程保持。

Android系统选图界面无法由应用统一改成此交互，因此新增应用内相册页。只在用户主动进入该功能时使用照片读取权限：Android13+读取图片、Android14+适配仅授权部分图片；旧系统的READ_EXTERNAL_STORAGE限定最高SDK32。不申请视频、写存储、定位或全盘文件权限。部分授权时只显示授权的照片，页内可重新选择授权内容或打开系统权限设置。拒绝时可返回使用系统相册多选或文件夹范围。

参考：[Android官方自定义相册与部分照片授权](https://developer.android.com/about/versions/14/changes/partial-photo-video-access)。按用户要求从“我的”移除权限与隐私入口；相册授权说明与APK权限审计同步更新。系统提供的图片流按原有校验保存，应用不主动压缩替换原片。

## 页面布局

- 云盘：“相册选择 / 文件夹范围 / 恢复上次”固定同排，系统多选与本机收题放次级操作，详细说明折叠。缩短标题、间距与空态，不把长孩子名重复放入云图标题。仍明确显示当前孩子。
- 拍题：三个添加入口同排，完成选择独立一行，已选数量和下一步清楚分开。
- 首页：集中拍照、选图、云盘入口及本机待提交照片。处理确认后返回首页；本机原片和恢复入口折叠，无待提交项时不显示空上传面板。待上传提醒标在首页。
- 题目：移除重复的拍照、选图、上传及恢复入口。按科目筛选错题，错题本/知识点归纳/原题照片同排。知识点按已保存字段聚合，同题去重、同名跨科分开，未校对题目标注提示，可展开查看相关题。举一反三明确标为准备中，未生成练习题。
- 我的：用户名、密码、退出登录放在家庭账号同卡同排。移除权限与隐私入口。检查更新与下载更新/已是最新版本同排，下载详情按需展开；检查失败不会误显示最新。
- 学生档案：每人独立卡片，显示年级、当前标记、错题道数、题目照片张数、待校对张数，简述已整理题数及云盘保存张数。点击进入该孩子的题目。统计失败或旧服务不支持时显示横线，不伪装成零。
- 照片调整/本机原片：窄屏操作可并排，保留必要触摸区域。首页及题目核对页进行窄屏回归。

## 验证与交付边界

学生统计使用认证接口 `GET /students?overview=1`，只返回当前家庭的计数，不附带照片或题干。与普通学生列表保持兼容；按学生ID分组、不按昵称，软删除照片不计入。无明确学生归属的历史照片单独提示，不套用大宝默认值。云盘保存数量与题目照片数量分开，避免将备份误算为已分析题目。

纯Java范围选择测试覆盖跨屏451张、正反方向、两端包含、同点、重叠范围、逐张取消、10万项紧凑保存、恢复边界及450项持久批次顺序。原生Android编译验证通过。浏览器桥验证只证明入口接线与导入/上传流程，不代替Android权限弹框和原生缩略图页验收。

最终测试计数、签名、公开下载与增量重建证据在发布后补齐。真机的相册授权、缩略图滚动、选起止点、进程恢复及覆盖安装仍待实际设备验收。
