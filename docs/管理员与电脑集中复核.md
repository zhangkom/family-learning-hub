# 管理员与电脑集中复核

管理入口为 `https://123.207.232.151/family-learning/admin`。这是电脑网页管理功能，现有Android 0.3.10通过原接口读取更新后的解析，不需要专门升级APK。

## 管理员

专用账号名为 `admin`，角色绑定账号内部ID，不因用户名相同而授予权限。只能由工程主机上的 `tools/admin-provision.mjs` 初始化，输入密码来自标准输入；遇到已存在的admin不会重置或提权。首次初始化仍要求更换随机初始密码。2026-10-03 用户明确指定个人使用的管理员密码，管理员改密下限调整为5个字符，并在主机完成该账号的密码设置与首次改密状态清除；普通账号注册和改密仍至少6个字符。登录验证已有密码，不用新密码长度规则阻挡已有账号。修改密码撤销原登录和电脑复核授权。真实密码只保存在私有配置，不写入本说明或源码。

腾讯主机的工程父目录是私有目录，初始化工具须使用正式服务相同的systemd私有挂载、`family-learning-app`身份和`FAMILY_DATA_DIR`，只读挂载冻结运行目录、读写挂载正式data。不要为执行命令放宽父目录权限。2026-10-03已完成一次初始化，后续不要重复创建或重置admin。

后台分别显示普通用户、管理员、学生、题目和云盘原图数量。可搜索账号，查看学生档案、全部题目、上传资料、云盘图片、练习、能力分析及完整家庭学习记录。管理员只能查看应用实际收集的信息；不提供密码、密码哈希、会话令牌或服务器模型密钥。未知历史学生归属标为待核对，管理查询不猜造归属或创建默认档案。

所有管理数据、图片和写操作由服务器校验管理角色。普通账号即使知道网址也无权限。网页写请求校验同源，管理读取和修改留操作记录，响应不公开缓存。

## 一次完整的电脑复核

1. 登录管理后台，在“全部题目”中按账号、科目、未解答／解析有疑问／已收错题本筛选，勾选需要处理的题目。可以跨页选择；每个复核批次1至100题。这是复核工作量限制，与无限张数的图片上传无关。
2. 创建批次，点击“连接电脑 Codex”，下载本批次的授权JSON文件。授权只允许读取所选题目及题图、提交结果，12小时过期。整个批次保留7天的外部处理窗口，可以提前关闭授权。
3. 在已登录的Codex中提供该本机文件的路径，请它读取本批所有题图、独立解题、核对旧答案，保存复核结果。不得把ChatGPT登录凭据复制到学习服务器。提供的是学习系统自己的有限授权。
4. 回到后台刷新，逐题对比新旧题干、答案、步骤、知识点和不确定项。点击“确认并应用到原题”后，原来的题目编号和错题收录保持，手机重新读取题目即可看到新解析。题干转写如需替换，额外勾选“同时采用已核对的复核题干”；改变共用条件会将关联小问标为需要重新核对。
5. 发现问题可回退本次修改。应用前若原题已改动，或回退前又出现新编辑，会报冲突并保留当前内容，不覆盖新数据。完成后关闭外部复核授权。

复核结果只写答案、讲解、知识点及明确选择的题干，不替换原件、题框或学生原始作答。历史原解析保存在批次快照和扫描版本内，操作记录包含管理员身份。已有练习保持当时的题目快照；能力分析按已有材料版本规则标记变化，不伪造新的练习成绩。

## 在当前Codex电脑直接处理

源码工程内提供无需配置新MCP连接的命令行接口。它与MCP使用同一受限服务，不调用DeepSeek，也不自行调用OpenAI API。执行`pull`只下载资料；解题由当前已登录的Codex在实际查看图片后完成，受其账号可用模型和用量限制。

```powershell
node scripts/prism-review-cli.mjs pull "C:\你的下载目录\knowledge-prism-review-批次编号.json"
# Codex 逐张查看 temp/pc-review/<批次编号>/*.jpg，读取同名JSON和batch.json，
# 独立求解并写出 result.json；不能只照抄旧答案，也不能假称经过另一模型复核。
node scripts/prism-review-cli.mjs submit "C:\你的下载目录\knowledge-prism-review-批次编号.json" "temp/pc-review/批次编号/result.json"
```

暂存题图只在忽略的 `temp/pc-review/` 中，不进入Git、APK、公开目录或合成测试报告。授权文件不输出到日志，不能公开分享。超时、失效或关闭后重新在后台授权；断线重交相同结果不会重复创建版本。

跨页和长题图按可读尺寸分片下载。新版服务通过批次的 `imagePartsVersion: 1` 声明支持；每题 JSON 的 `imageFiles` 列出完整、有序的图片文件，必须逐一查看，不能只读第一张。每片最多1800像素宽、2400像素高，长图相邻片保留96像素重叠；一题最多24片、合计24 MiB，超限明确失败，不丢弃后半题。未声明能力的旧服务仍使用单图接口。

`pull-status.json` 只有全部所选题目的图片和元数据下载成功才标记 `complete`；中途断线保留未完成状态，`submit` 拒绝把它当完整批次提交。服务已声明分片后，任何一片失败都不得降级成只读一张图片。命令行及 MCP 脚本共用 `scripts/prism-review-images.mjs`，单独复制工具时须一起保留该文件。

## 可选MCP连接

若希望Codex直接看到工具，在Codex的MCP设置中添加STDIO服务：命令为本机Node可执行程序，参数依次为工程 `scripts/prism-review-mcp.mjs` 的绝对路径和本批授权文件的绝对路径。需要工程依赖已安装。也可用环境变量 `PRISM_REVIEW_GRANT` 指向授权文件。每次换批次更换文件后重新连接。

三个工具分别为 `get_review_batch`（读取已选列表）、`get_question`（读取上下文及实际图片）、`submit_review`（提交待核对提案）。MCP连接内没有读取过图片的题目不能提交；接口不提供读所有账号、另选题目、直接发布答案或提权功能。

新版 `get_question` 返回该题全部分片；只有整组读取成功，连接才记录该题可提交。题干、题框、作答或题图版本发生变化，旧提案的指纹失效，管理员应用时返回冲突，不能把旧图的解法写入已修订的题。

此接入使用Codex支持的本地STDIO MCP连接，详见 [OpenAI官方MCP文档](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)。未自动修改用户全局Codex配置，也没有模拟操作ChatGPT网页。

## 结果约定

`provider`填写真实来源`codex`或`chatgpt`，`model`填写真实模型名或`unknown`。`summary`说明改动；`knowledgePoints`为知识点数组；`result`含`transcribedPrompt`、`referenceAnswer`、`explanation`、`answerEvidence`、`errorHypotheses`、`uncertainties`。提交还需精确匹配读取时的`fingerprint`。

必须实际读取题图，包括配图、共用条件、单位和笔迹。图文不清、条件不全时明确列出问题，不能猜答案。参考解法不能填为学生原始作答；不明作者标为unknown，错因只引用明确学生证据。纸面错题／重点题的收录标准仍以 [错题与重点题目收录标准](错题与重点题目收录标准.md) 为准。本功能不会因换了模型就保证答案正确，因此保留对比核对环节。
