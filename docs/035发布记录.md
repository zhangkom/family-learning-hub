# 0.3.5 整批上传、同名处理与页面精简

版本0.3.5/code17。按用户最新要求取消200张分组，上传总数与相册导入、历史完成记录分开。全流程复查涉及首页、题目、我的、账号、更新、拍照选图、照片调整、框题和图片云盘。

## 上传计数与恢复

用户截图显示200/200、共2组。2026-10-02北京时间17:42附近只读核实：服务器两条记录分别是此前5张和本次195张，都已接收；没有出现某批200张后服务器拒收后续的证据。手机最初选了多少、是否有权限或导入失败，无法只凭服务器还原，不能声称已查明原生选图截断的唯一原因。

新选择不按200拆分，一次500张保留为一份选择，进度始终以全部所选照片计数；继续添加未完成任务会增加总数。之前已经全部完成的本机记录在新选择时退出当前进度，云端原图及服务器回执不变。尚未导入的本机选择也计入分母，显示未进入队列的数量和继续读取入口。

导入显示“正在保存到本机 X/N”。离开或中断不会自动取消未完成的本机选择，原生持久记录继续保留；只有明确“忽略这批未导入项”才取消。恢复沿用原片编号，避免重复入队。上传成功需核对学生、编号、大小、哈希和回执；丢回执后沿用同一请求编号重试。新版本不再有200张分组或每小时600张的固定数量限制；原有单张格式/大小、磁盘空间和串行资源控制保留。

旧版100/200张数据库约束迁移为正数计数，全部已有记录保留。兼容能力字段maxBatchItems使用可安全表达的最大整数；旧APK可继续按其原流程使用，新APK不依赖200张上限。

## 同名选择

上传前按同一家庭、同一学生的完整显示文件名检查。发现冲突，暂停这张等待选择：覆盖；自动加_1后缀（被占用则_2等，放在扩展名前）；自己编辑（扩展名保留）。同一选择中后续同名项也会检查。文件名用于显示，独立编号和内容哈希继续用于确认身份。

覆盖先保存新原图并验证，事务中检查用户所确认的同名集合未变化，再将旧记录标为已替换。旧原件不移动不删除，旧上传回执和历史读取仍有效；当前云图列表及学生统计只计算替换后的记录。失败、取消或发生竞争时不会先删除旧图。确认令牌和最终名称在上传前写入本机队列，回执丢失后重试不会再次覆盖。

## 页面精简

- 删除游客首页功能规划卡、重复注册提示、未实现的功能弹窗，以及题目页举一反三“准备中”占位。
- 删除我的页重复的网站跳转和资料说明；账号操作、学生卡片、版本检查保留。
- 题目页用一行统计，切换错题/知识点/原题；只显示当前有内容的科目，原题照片不显示无效科目筛选。
- 云盘三个选图主按钮同排；移除分组说明和组数。空队列隐藏，全部完成后隐藏无效上传/停止按钮。
- 收题列表和本机上传列表限制展示高度，照片多时在列表内滚动；框题页去掉重复指导和不能使用的整张识别按钮。
- 照片调整统一蓝白色调，一次突出当前主要操作。Android安全区域由统一根容器接收Capacitor变量，避免云盘返回键与状态栏、底部手势区域重叠。
