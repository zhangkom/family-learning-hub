# 双宝强化训练系统

## 产品定位

这不是“题目越多越好”的题库，而是一套家庭一对一学习闭环：

1. 按课程章节选择一张训练页；
2. 孩子独立、限时、纸笔完成；
3. 家长用网页答案区批改并追问思路；
4. 将真正不会的题勾入错题本；
5. 系统安排第 2、7、30 天重做；
6. 根据错因继续生成同知识点、不同情境的原创变式。

“强化训练”“每日难点”“错题复盘”是三条相连但不混放的产品线：强化训练负责系统覆盖，每日难点负责概念精讲，错题复盘负责个体漏洞。

## 首批内容

- 小宝：初一数学七年级上册第一章“丰富的图形世界”，共 8 张 A4 练习，从基础识别逐步走到空间推理与开放探究。
- 大宝：高二数学、物理、化学、生物各 1 张周练样板，分别训练椭圆、电场、化学平衡和遗传规律。
- 每道题具备稳定题号、知识点、难度、答案、讲解、原创出处和答题空间。

## 课程依据与版本假设

- 初中内容依据教育部《义务教育数学课程标准（2022年版）》中的“图形与几何”。深圳市公开教材选用目录可确认七年级数学使用北师大版体系；不同学校、年份和印次的具体目录仍需以孩子手中教材为准。
- 高中内容依据教育部《普通高中课程方案和学科课程标准（2017年版2020年修订）》。高二各校选修模块进度可能不同，因此系统将教材版本和章节设计为可调整字段。
- 深圳 2025—2026 学年校历明确要求高中执行上述国家课程方案；广东高考采用“3+1+2”结构。

## 商用内容边界

- 不直接复制《必刷题》等商业教辅的题干、图形、答案或编排。
- 只研究公开课程标准所要求的知识、能力层级和常见题型结构，再重新设计情境、数值、设问与解法。
- 每道发布题保留平台原创 ID 和版本；若未来引用公开考试真题，应单独标明考试名称、年份、题号和官方来源，不与原创题混标。
- 正式对外收费前应增加内容审校、隐私政策、服务条款、未成年人数据保护、账号权限和内容版本发布流程。

## 下一阶段

1. 请家长提供两位孩子课本目录和最近一次考试范围，用于锁定实际章节顺序。
2. 小宝继续建设七上数学后续章节，再开英语单元训练。
3. 大宝根据学校本周进度扩展四科周练，并把扫描错题转成知识诊断和原创变式。
4. 增加家长端学习画像：掌握度、重复错因、复习到期和章节完成率。
