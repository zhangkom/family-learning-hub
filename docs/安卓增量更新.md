# 安卓增量更新

0.2.5（versionCode 7）是完整安装的能力引导版本。现有 0.2.4 及更早版本只支持完整 APK。从后续 code > 7 的版本开始，可以向已安装 code >= 7 的客户端提供增量；首次安装、基线不匹配、分包安装、补丁不够省流量或任何校验失败，均下载完整 APK。每次最多尝试一个补丁，不串联多个历史补丁；不静默安装、不在启动时自动下载。

服务器发布器与客户端均保留完整 APK 字段。补丁只减少传输量；客户端仍需在应用私有缓存重建完整 APK，经原有包名、签名和递增版本检查后交给 Android 系统安装器。代码不解包重压或重新签名 APK。

## 工程内的文件位置

所有正式发布输入，包括 APK、补丁和私有补丁清单，都在腾讯工程 `artifacts/android/<发布批次>/`；公共下载副本位于同工程 `artifacts/public/android/`。验证与临时重建在私有批次或 `temp/development/` 中，配置在 `config/`，发布快照在 `backups/releases/`。本地验证在工作树忽略目录 `work/` 中。不向公开目录暴露基线清单、完整源码包、测试原图或凭据。

## 生成和发布

生成器只依赖 Python 标准库，读取 ZIP 的原始压缩字节范围，相同范围生成 COPY，其余字节生成 DATA。APK 签名块与其他差异字节照原样传输。

```sh
python3 scripts/apk_delta.py create --base /private/base.apk --target /private/target.apk --from-version-code 7 --to-version-code 8 --output-dir /home/ubuntu/codex_project/workspace_own/family-learning-hub/artifacts/android/<发布批次>
python3 -m unittest discover -s scripts -p test_apk_delta.py -v
```

生成器会先逐字节重建并验证，再给出 `delta-7-to-8.json` 和包含 SHA-256 前 16 位的固定补丁文件。`eligibleForPublication` 是提示，发布器独立复核全部条件。多基线发布可合并同一目标的 `deltas` 数组，最多 4 个；每个 fromVersionCode 唯一，不得改动补丁字段。生成质量取决于两版差异，实测比例不是未来版本承诺。

在原有 `publish-apk.py` 参数上加 `--delta-manifest <本发布批次>/delta-7-to-8.json`。服务器 `runtime/tools/` 同时安装 `publish-apk.py` 与 `apk_delta.py`。发布器核对目标 APK、发布登记中唯一的正式基线 APK、补丁字节数/哈希、基线哈希，以及重新合成的目标字节数/哈希。只有补丁 **严格小于目标的 80%** 且至少节省 **65536 字节** 才允许发布。无合适补丁时省略参数，完整 APK 正常发布；主动传入不合格清单会在发布前失败，不悄悄忽略错误。

历史 APK、JSON、补丁不可覆盖。重试相同发布必须保持相同增量清单；不能事后向已发布版本追加补丁。发布器只开放登记的精确文件路径，补丁 MIME 为 `application/octet-stream`，禁用额外 gzip，不设置 `Content-Encoding`；公网完整下载后复核字节数/哈希和无重定向。latest.json 仍保留原有完整 APK 字段，增加可选数组：

```json
{"deltas":[{"format":"zai-copy-v1","fromVersionCode":7,"baseBytes":1234567,"baseSha256":"<64 lowercase hex>","downloadUrl":"https://123.207.232.151/family-learning/downloads/android/family-learning-7-to-8-<patch sha first16>.zaidelta.gz","bytes":123456,"sha256":"<64 lowercase hex>"}]}
```

上例数值为结构示例，不是可安装清单。旧客户端忽略该可选字段。

## zai-copy-v1 字节约定

文件是单个 gzip member，压缩方法 8，FLG=0（固定 10 字节头，不含名称、注释、额外字段或头 CRC）。必须验证 gzip CRC/ISIZE，拒绝尾随压缩字节、额外 member（包括空 member）和任何尾随解压字节。

解压后所有整数为无符号大端。头部 92 字节：`ZAI-DLT1`（8 字节 ASCII）、基线长度 u64、目标长度 u64、基线 SHA-256 原始32字节、目标 SHA-256 原始32字节、操作数 u32。操作数范围 1–100000。

- COPY：opcode 0、基线偏移 u64、长度 u32；从已安装 APK 原字节拷贝。
- DATA：opcode 1、长度 u32、对应长度的原始字节。

APK 和补丁长度均限定 1–256 MiB。所有操作长度必须大于零，偏移/长度/累计输出在读取前检查；拒绝未知 opcode、截断、不完整输出和溢出。仅读指定数量操作，完成后必须到达严格 EOF。流式读写缓冲 64 KiB，客户端设总操作超时。客户端先核 `applicationInfo.sourceDir` 基线 SHA/大小，再下载补丁并核 SHA/大小；合成器再次验证基线，头部目标必须与完整 APK 清单匹配，最终重建 SHA/大小必须完全匹配。失败删临时重建文件，保留完整包回退。

## 已做离线验证

2026-10-01 用真实已签名 0.2.3/code5 → 0.2.4/code6 进行离线实验：完整目标 6,690,297 字节；补丁 121,598 字节，节省 **98.182%**，10 个操作。Python 参考实现与 Android 生产 Java 合成类均重建到目标 SHA-256 `e44876c8ab20ff7b8e6f1282d6c02e040e16ec9ad1d7f42b2d16c077dcb345e8`。这组历史版本没有增量安装能力，仅作为交叉验证，禁止加入公共 latest.json。

含新增原生代码的 0.2.4/code6 → 0.2.5/code7 实测补丁为 3,465,657 字节，完整目标 6,692,593 字节，节省 **48.217%**，12 个操作；Python 和生产 Java 合成类均逐字节还原到目标 `035d8f365d4c04b4a06d19df8aa2112ab8f215c2af231601fc0dcaf77a5c068b`。此基线同样不支持增量，仅作离线证据；0.2.5 已发布完整包，清单不含 deltas。后续必须逐版测量，不能承诺固定缩减比例。

Python 测试覆盖 COPY/DATA、ZIP 插入/删除/修改/重排、确定性、错误基线/哈希/尺寸、操作越界、截断、CRC 错误、额外 gzip member、尾随内容、保留已有输出，以及发布清单路径/版本/节省阈值/基线注册校验。Java 端还需结合客户端测试验证失败回退与系统安装流程；离线重建通过不等于完成真机升级测试。

协议依据：[gzip RFC 1952](https://www.rfc-editor.org/info/rfc1952/)。APK 签名机制参见 [Android APK Signature Scheme v2](https://source.android.com/docs/security/features/apksigning/v2)。
