# Family Learning Hub 工程目录

本项目的服务器文件集中于 `/home/ubuntu/codex_project/workspace_own/family-learning-hub/`。源码、运行文件、真实数据及临时文件分别管理：

```text
family-learning-hub/
├── code/                    源码、Git 历史、依赖、开发脚本及文档
├── runtime/
│   ├── releases/            已部署版本，保留旧版本供回退
│   ├── current -> releases/ 当前线上版本
│   ├── development-build/  开发构建产物
│   ├── tools/               线上使用的备份等工具副本
│   └── logs/                网站、备份日志及迁移前日志导出
├── data/                    私有 SQLite、归档扫描原件与逐题记录
├── backups/
│   ├── daily/               每日完整快照（最近 30 份）
│   ├── releases/            发布前备份
│   └── migrations/          目录迁移前快照、文件校验、回退资料
├── config/
│   ├── *.env                私有密钥、启用码等环境配置
│   ├── systemd/             网站服务、备份服务和定时器配置
│   ├── nginx/               本项目反向代理路径配置
│   └── logrotate/           本项目日志轮转规则
├── temp/
│   ├── deployments/         上传、部署暂存与旧上传包
│   ├── development/         开发测试数据、交接包及验证日志
│   ├── service/             服务进程临时文件
│   ├── images/              图片处理暂存（预留，非归档原件）
│   └── videos/              视频处理暂存（预留）
└── artifacts/qa/            测试截图、PDF 和验证产物
```

`code/work`、`code/outputs` 通过工程内部链接对应 `temp/development` 和 `artifacts/qa`。`code/dist` 链接到 `runtime/development-build`；`npm run build:self-hosted` 校验并保留这个链接，将生成内容放在运行文件目录。这些目录及链接已被 Git 忽略。正式学习数据不经开发构建或临时测试目录读取。

共享 Node.js、Nginx 程序、HTTPS 证书和系统日志基础设施属于服务器公共环境，不属于本项目文件。`/etc/systemd/system`、`/etc/nginx/snippets` 中仅保留系统需要的链接，指向工程 `config/` 中的实际配置。每日备份服务直接调用工程内的日志轮转规则。旧 `/etc/family-learning-*.env` 入口也只保留链接；`/opt/family-learning-hub` 与 `/var/lib/.../family-learning-hub` 不再存放本项目文件。

`config/` 和私有备份仅 root 可读。`data/` 与每日备份由专用用户 `family-learning-app` 持有，权限 0700；服务仅在 systemd 私有视图中看到指定的运行文件、数据和暂存目录，不放宽工程父目录对其他项目的访问权限。站点日志按天轮转，保留 14 份。

在服务器继续开发：

```sh
cd /home/ubuntu/codex_project/workspace_own/family-learning-hub/code
git status --short --branch
npm test
npx tsc --noEmit
npm run build:self-hosted
```

备份恢复与发布步骤见 [腾讯云部署](腾讯云部署.md)。不要移动共享证书续期任务，也不要操作同级 `7080laoyou` 的上传或存档。
