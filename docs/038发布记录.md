# 0.3.8 发布前验收记录

本文件记录当前改造，目标版本0.3.8/code20，尚未发布。冻结源码、安装包、生产切换、真实五张照片与公网验证结果在完成后补充。

## 本次功能

首页最上方为录错题、批量错题上传两个大入口，四个学习栏目在下方。原题照片与图片云盘为紧凑的次要入口；批量收题复用相册起止范围选择。

题目页仅错题本、能力图谱两个大字页签。错题本按照片上传顺序排序，同一照片内题序不变；全部与数学、语文、英语、地理、物理、化学、生物七科筛选使用同一序列。历史未分科题目单独可见，但不进入个人学科图谱。

题卡显示试卷式题干及真实配图，未单独框出配图时保留完整原题框。原图按钮在同卡内切换原题框，显示明确状态；临时本机读取繁忙有限重试，永久缺图可重试或由用户主动从云端恢复。Android不自动下载题图。

能力图谱由已确认且收录的多道同科错题生成，AI跨题分析后独立复核引用、知识点和能力维度。每项补强方向至少引用两道错题。具体错因需要真实作答证据；仅有题干时只能给共同考点的待核对建议。七科各六维，年级重点为参考，不假定教材顺序。

分数由服务端按冻结的独立练习/复测成绩计算，按原题均衡；至少三道不同练习并关联两道原题才有数值，其余待评估，不填零。提示后作答、重复原题挑战、无依据批改、重复题干不进入独立评分。满分不等于长期掌握。报告绑定家庭、孩子、科目、来源和学习快照，变化后标过期。可从维度看依据、回原题、练习、复测；相同请求重试不重复创建任务，源资料未变化时不重复触发分析。

## 已进行的验证

- 500张隔离HTTP云盘整批上传，5/500、200/500、500/500；同名三选、丢回执重试、部分导入恢复。
- 210张批量收题、连续拍摄、选图取消、按照片选科及学生隔离。
- 320/390/768题卡，原生桥精确本机路径、哈希、繁忙重试、主动恢复，无自动云下载。
- 首页双入口大于四学习栏目，320/360/390/768布局，题目页仅两页签，全部与七科筛选，账号操作和更新状态。
- 实际隔离后端+worker的拍题、校对、三道变式、提示后修正、难题三级提示、两次独立复测、原题返回、学习草稿、档案统计。
- 实际隔离后端+worker的两数学错题与一物理题，创建丢回执幂等、两原题引用、无成绩不评分、维度点选、原题/练习衔接、改题过期、读取断网恢复、跨孩子隔离。
- 雷达独立组件：完整/部分/全未知数值、真实0与未知区分、异常分数不绘制、长标签、触摸/键盘、无ResizeObserver兼容。

上述流程使用合成题图及合成模型；真实照片验证按用户要求在功能完整检查后执行。没有连接物理Android设备，浏览器原生桥不等于真机验收。首轮Windows全量测试发现临时目录rename被占用；须完成有界原子发布修复及复验，不能把重试通过表述为从未失败。
