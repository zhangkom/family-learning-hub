# 数据与跨设备方案及完成情况

核对日期：2026-10-01。本文描述腾讯云正式版本；仓库中保留的 Sites D1 / R2 接口属于另一种部署方式，不是当前腾讯云的数据存储。

## 四阶段计划核对

| 阶段 | 当前状态 | 已有功能 | 尚未完成的部分 |
| --- | --- | --- | --- |
| 数据保存与同步 | 基础要求已完成 | 家庭账号、两个孩子记录隔离、SQLite 持久化、跨设备合并、断网补传、JSON 导入导出、每日完整备份与恢复验证 | 当前只开放一个家庭账号；不是多家庭公开注册平台 |
| 扫描归档 | 基础要求已完成 | 图片/PDF 私有上传、原件预览、旋转预览、出处、逐题编辑、版本冲突检查、确认收录错题、回收站恢复、旧扫描兼容 | PDF 识题不在这一阶段完成；现有旋转只改变预览，不改写原件 |
| AI 讲题 | 基础版已完成 | DeepSeek 图片识题；保留题干、图示文字描述、孩子原答案；生成参考答案、分步讲解、知识点和待确认事项；家长勾选后收录 | PDF 自动识题、已整理题目单独请求 AI 讲解、多轮追问及对话保存、AI 变式题、科学图示生成与版本保存 |
| 家长复盘 | 基础版已完成 | 近七日作答数量、独立答对、保留错题数、内置方法课的到期复习与重复错误 | 扫描错题的重做记录与掌握度、自动周报/月报、长期趋势、按真实错因生成下周任务 |

结论：四个阶段均已有可使用的入口，但完整学习闭环还没有完成。当前不能把“扫描题目已存入错题本”视为“孩子已经重做并掌握”。

## 已核验的行为

- 同一账号在两个独立浏览器中看到相同错题；断网作答联网后补传，首次错误不会被后续正确答案覆盖。
- 注销后无法调用私人接口，浏览器界面不继续显示该账号记录。
- 上传内容校验、同源限制、不同家庭隔离、编辑版本冲突和草稿/确认结果分离均有测试。
- 旧版扫描由首次创建的家庭账号继承，原件未改动；默认归大宝。
- 用合成试题调用真实 DeepSeek 接口，识别得到孩子答案 `6`、参考答案 `5` 和分步讲解，再由家长勾选归档。
- 完整备份经文件哈希校验，并在独立实例恢复了账号、作答记录、错题和扫描原件。
- 42 项单元/API 测试、类型检查、本项目范围 lint、独立构建及浏览器流程通过。通用 UI 组件的既有全仓库 lint 问题单独保留。

## 复习与 AI 的实际边界

内置方法课已有同类练习、作答历史和复习建议。扫描错题目前只有原件、核对结果、首次错答以及初始第 2/7/30 天复习日期，没有与之对应的网页重做提交入口。

家长复盘的“到期复习”和“反复出错的方法”从内置方法课作答计算。扫描题计入错题数量，但不会凭扫描上传或人工核对就计为一次独立作答，也尚未进入动态掌握度统计。

当前 AI 在新扫描识题时一次生成讲解。已有整理内容或确认结果的扫描会禁止重新识题，避免覆盖人工核对；另行请求讲解和保留多轮对话需要后续实现。图示字段目前为文字描述。

## 下一步顺序

1. 为已归档题目增加单独 AI 讲解入口、多轮追问及可追溯版本。
2. 把扫描错题接入独立重做、同类变式和 2/7/30 天复习队列，记录真实作答与家长核对结果。
3. 将这些记录纳入家长复盘，生成有证据的周报、错因变化及下周建议。
4. 补充 PDF 分页识题及学科图示，继续保留原件和家长确认步骤。

构建、发布与回退见 [腾讯云部署](腾讯云部署.md)。两台电脑同时开发时，先提交本机修改，再拉取和解决冲突，不用 `git reset --hard` 覆盖另一端工作。
