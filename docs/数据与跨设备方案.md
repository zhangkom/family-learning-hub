# 数据与跨设备方案

## 两条同步通道

| 内容 | 存放位置 | 工作电脑与家里电脑如何同步 |
| --- | --- | --- |
| 网页代码、题库模板、课程标签 | GitHub 仓库 | `git pull` / `git push` |
| 错题、孩子答案、复习日期 | 私人 D1 数据库 | 登录同一个网站账号自动读取 |
| 扫描件、照片、PDF | 私人 R2 文件空间 | 登录同一个网站账号自动读取 |

真实学习资料不写入源码、Git 提交或浏览器公开链接。每条数据库记录都带 `owner_id`，所有读取和写入都先从平台认证头中确认当前用户，再按 `owner_id` 查询。扫描件使用随机 UUID 作为对象名，原始文件名只作为显示信息保存。

## 已实现的数据闭环

### 小宝

1. 每日选择数学或英语难点。
2. 提交答案后在浏览器内即时判定。
3. 答错时记录题目、孩子答案、正确答案、知识点和出处。
4. 自动生成第 2、7、30 天复习日期。
5. 云端不可用时暂存当前设备，恢复后仍可继续使用。

### 大宝

1. 选择数学、物理、化学或生物。
2. 上传 JPG、PNG、WebP 或 PDF，单个不超过 8 MB。
3. 服务端同时校验声明类型和文件头，防止伪装格式。
4. 题目出处为必填项，历史列表可重新打开原扫描件。
5. 扫描记录按当前登录用户隔离，接口最多返回最近 100 条。

## 网页内 AI 讲题的边界

当前版本完成了“安全收集—错题归档—跨设备回看”的底座，并提供讲题卡结构。它还没有在网页后台调用模型自动识图和生成讲解；若下一阶段接入，应使用服务端模型 API，并补充：

- 扫描件 OCR 与题目条件复核；
- 知识点、分步解答、规范答案和变式题的结构化字段；
- 物理受力图、函数图像、化学装置图、生物过程图的生成与版本保存；
- 孩子追问与回答的对话记录；
- 家长确认后再保存模型结论，避免识图错误直接进入错题本。

API 密钥只能配置在服务端密钥存储中，不能提交到 Git，也不能放进浏览器代码。

## Git 日常操作

工作电脑开始：

```powershell
git switch main
git pull --ff-only
npm install
npm run dev
```

结束开发：

```powershell
npm test
npm run build
git add -A
git commit -m "描述本次改动"
git push
```

家里电脑重复同样流程。若两台电脑同时改了代码，应先提交当前工作，再拉取并解决冲突；不要使用 `git reset --hard` 覆盖另一台电脑的修改。
