# 网页版与安卓对齐

2026-10-03，网页版以安卓 0.3.14 为功能基线，复用 `clients/android/src` 的界面和业务代码。部署网页不修改已发布 APK 的版本、下载入口或差异包。

## 共用的流程

- 首页：录错题、批量错题上传两个主入口在上，温故知新、融会贯通、知识星图、破茧成蝶在下。学习入口读取当前学生的实际记录。
- 题目：错题本／能力图谱、科目和收录类型筛选、排序、来源试卷与原题号、知识点／原图切换、1 至 5 星难度、图文题干及清晰配图。
- 原题照片：框题、人工校对、收录复核、分析进度、查看整张来源原件及跨页材料。
- 学习：变式练习、难题突破、提示、答题、复测和个人能力证据沿用同一服务器接口与校验规则。
- Word：默认题目卷，可另选已核对的答案解析；导出前检查全部所选题目，不静默遗漏缺图或待核对题。
- 图片云盘：保留原文件名，整批计数，不按 100／200 张截断；同名选择覆盖、后缀或手动修改。中断保留已确认的本机文件与上传回执。
- 我的：家庭账号操作集中显示，学生分别展示真实统计；管理员按服务器返回的账号角色进入原管理后台。

## 浏览器适配

网页登录通过 `/api/family/workspace` 使用 HttpOnly、SameSite Cookie，写入严格校验同源。登录凭据不进入网页存储或 URL。安卓继续使用原有独立 Bearer 会话。刷新、旧页面链接及浏览器前进后退由网页地址恢复对应栏目。

浏览器图片选择使用系统文件选择器，电脑支持 Shift 连续多选、Ctrl 多选和文件夹选择；文件夹按相对路径自然排序。安卓保留原生相册起止范围页。网页录题保留本机草稿，确认后上传并将已确认的题图存入浏览器缓存；云盘备份不会自动发起分析。

显示题目时优先读取当前站点／账号／学生的已校验本机缓存。缺失或损坏时自动恢复，失败才显示重试。网页缓存属于当前浏览器，清理浏览器数据后需重新恢复；不能把安卓私有目录和电脑浏览器当作同一份存储。

电脑使用顶部导航和适合阅读的题卡宽度；手机浏览器使用底部导航。Word 交给浏览器下载。网页提供“下载安卓应用”，不把 APK 检查更新误称为网页更新。网页选图不提供安卓原生相机、安装器或上传前的原生透视矫正界面；录入后仍可在题目详情框选、校对。

## 构建与验证

1. 在根目录及 `clients/android` 各运行 `npm ci`（Node.js 24）。
2. `npm run build:self-hosted` 先构建共享网页客户端至被 Git 忽略的 `public/web-client/`，再打包服务器。入口模块与 CSS 使用内容哈希，由 manifest 指定。
3. 根目录测试、类型检查、作用域 lint 与客户端测试、类型检查、lint 必须通过；运行 `scripts/smoke-self-hosted.mjs` 检查发布资源和认证边界。
4. 独立合成数据浏览器验收覆盖选图、取消、续传、登录刷新、学生隔离、题图恢复、知识点、星级、Word 与前后导航。真实资料只读对齐；合成模型测试不当作真实解题正确率或安卓真机验收。
5. 部署前一致性备份，检查原件、图片修订、打印核对、账号及学习数据；部署后确认已发布 APK 与公开版本信息原样保留。
