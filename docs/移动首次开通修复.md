# 移动首次开通修复：0.2.1

原 0.2.0 APK 只有登录入口，尚未开通家庭的用户无法直接开始使用。0.2.1 增加 App 内首次注册：输入私下提供的启用码、自设家庭账号和密码，成功后直接进入已登录状态。已有家庭继续登录，不开放无启用码注册，也不重置既有账号。

## 接口与并发规则

- `GET /family-learning/api/mobile/v1/setup` 匿名返回 `{enabled,needsSetup}`，只含两个布尔值，不返回账号信息或启用码。
- `POST /family-learning/api/mobile/v1/session/setup` 接收 `{username,password,setupToken}`，成功 200 返回 `{token,user,expiresAt}`，与移动登录相同，不设置 Cookie。
- 网站和手机共用启用码校验、限流、密码散列和首家庭创建事务；首个家庭沿用旧资料归属。账号、旧资料归属和登录凭证在同一事务内保存；手机与网页并发只会有一个成功，另一个返回 409。
- 保留精确 CORS：安卓来源 `https://localhost`，网站来源 `https://123.207.232.151`。无效输入 400、错误启用码 403、已开通 409、限流 429；显示响应中的安全错误说明。
