# 模型尝试审计与重试

2026-10-01 已部署后台 `887ee6c4148b6e5e9dd7de7c76bcede66b459ab5`，对应 [0.2.8 发布记录](028发布记录.md)。模型配置、质量参数及提示词未改，本次部署新增真实模型调用为 0。

移动后台队列 `runNextJob` 对每次已领取任务写一份 `data/model-audit/YYYY-MM-DD/<jobId>-<attempt>.json`。题目、原件、用户名、账号 ID、密钥、请求正文、模型原始响应和错误消息均不进入审计；仅关联不透明 job UUID。同步旧网页调用不经过此队列，不在本次逐次审计范围。进程崩溃或强制终止可能留下没有最终审计的尝试，不能将缺少日志当成没有发出请求。

记录包含入队/可运行/领取/结束 UTC 时间、总排队时间（后续尝试含退避）、可运行后等待、尝试总耗时，以及实际发生的读原件、单题裁剪、模型 HTTP 往返、JSON/结构校验耗时。HTTP 时间包含网络与供应商处理、返回正文读取，并非纯模型推理时间。不存在的阶段不补零。结果标记为 succeeded、retry_queued、failed 或 discarded（例如用户已改题框使迟到结果失效）。

仅记录供应商主机名、请求模型名、响应声明模型名、有限格式请求 ID 及白名单数字用量。未返回模型名/用量/合法 ID 时省略；响应 model 是供应商声明，不足以证明内部路由。用量支持 Chat Completions / Responses 的常见输入输出、推理、缓存 token 计数字段。其他字段忽略。

文件不超过 8 KiB，通过临时文件原子发布，目录 0700/文件 0600（Windows 仍受本机 ACL 控制）。最多保留 30 个 UTC 日期内、每天最多 1000 条，超出优先清除该日旧记录；到下一次尝试写入时执行维护，不承诺静止服务每天自动清理。拒绝审计根目录/日期目录为符号链接，清理仅针对匹配本功能的 JSON 文件。写失败只输出固定告警，不丢弃已保存结果，不为了补审计再次调用付费模型。

备份脚本已将合法的不可变审计文件纳入 manifest 与 SHA-256 核验；每日备份仍保留最近 30 份。历史快照可能保留超过在线 30 日期限的审计，发布前快照不自动清除。原件/审计文件与 SQLite 不是跨文件瞬时事务，新请求有可能不在当次备份中。恢复时保留 data 全部目录；本次没有数据库迁移，旧运行版本会忽略 model-audit，不应删除审计来回退。现有单题结构的旧版本回退限制仍适用。

重试保持每任务最多 3 次、现有 15 秒 × 已尝试次数退避和家庭 24 小时配额：

| 情形 | 处理 |
| --- | --- |
| 上游 400/404/422 等请求错误 | UPSTREAM_REQUEST，立即失败 |
| 上游 401/403 | UPSTREAM_AUTH，立即失败 |
| 上游 402 或明确白名单余额/配额错误码 | UPSTREAM_QUOTA，立即失败 |
| 上游 429（无明确配额错误码） | UPSTREAM_RATE_LIMIT，可重试 |
| 上游 5xx、408、网络中断/90 秒超时 | 可重试 |
| 输出截断、坏 JSON、结构不合格或过大 | MODEL_OUTPUT，停止自动重复，允许用户另行调整后重试 |
| 本家庭配额用尽、识题关闭/配置错误 | 不自动重复 |

供应商响应体不透传。未知 429 无法可靠区分繁忙和额度，仍按最多 3 次处理。未改变模型配置、thinking/reasoning、提示词、16000 token 上限、裁剪尺寸或 JPEG 质量；没有声称答案准确率或首答速度提升。

本地合成测试覆盖状态分类、限次、超时、额度、坏输出、迟到丢弃、审计写失败、元数据脱敏、保留上限、备份清单和数据库结构不变，未调用真实模型或解读用户照片。腾讯同服务身份独立合成队列验证真实裁剪→HTTP 桩→审计→备份，manifest 包含一条合成审计且逐文件哈希正确。
