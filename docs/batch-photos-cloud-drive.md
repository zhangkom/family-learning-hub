# 批量拍题与图片云盘

客户端 0.3.0 / versionCode 12 增加两条上传流程。APK 和后台发布结果以本版发布记录及公开版本清单为准。

## 使用方式

- **拍照收题 / 相册选图**：进入本批照片页，连续拍摄或多次从相册添加，累计最多 100 张。可移出不需要的照片。Android 原片先存手机，完成选择后逐张预览调整、确认，最后在题目资料页批量上传处理图。浏览器保存本机草稿，检查后批量上传。每次上传最多取当前孩子的 100 个待提交项。
- **批量上传图片 / 图片云盘**：首页和题目资料页都有入口，明确显示当前孩子。选择最多 100 张原图后，需要主动点击“开始上传”。云盘只保存原图，不创建扫描题目、不自动调用 AI，也不扫描或同步其他相册内容。
- 云盘支持 JPEG、PNG、WebP，单张最多 32 MiB、3200 万像素。超限或不支持的格式明确失败，不为了通过限制压缩原件。页面显示服务器返回的家庭配额和使用量。
- 云盘列表可分页浏览、打开预览和下载原图。预览使用私有缩略图；下载保留原始字节。Android 校验下载后弹系统保存位置，只有系统写入完成才显示保存成功；浏览器交给自身下载管理。

## 批次与恢复

拍题上传与云盘上传都逐张读取和发送，避免同时载入 100 张原图。每张显示状态，失败项保留；停止后不再启动下一张。在途请求可能已经到达服务器，后续按固定上传标识核对回执。

云盘待上传记录使用 IndexedDB，按服务、账号和孩子隔离，不保存登录令牌。网页照片保存 Blob，Android 保存私有原片引用。恢复页面不会自动上传。服务器按固定批次和照片请求 ID 处理重试，客户端核对孩子、大小、哈希及请求 ID 后才确认完成。

Android 系统相册选择使用 `ACTION_OPEN_DOCUMENT`，不增加广泛相册读取权限。原生私有批次保存选择 URI、固定原片 ID 和各项状态；逐张导入，已完成批次也可恢复。持久化交接完成后才能清理批次引用。明确取消未导入项时，不删除已经保存的原片。传统 Camera 活动恢复也保存全部多选引用。

拍题原片留手机的既有约定仍适用于拍题处理流程。用户主动选择图片云盘时，授权上传选中原片，两者不会暗中互换。

## 云端保存

服务器工程根目录为 `/home/ubuntu/codex_project/workspace_own/family-learning-hub`。云盘正式原件保存在 `data/<sha256(accountId)>/cloud-photos/<photoId>/original`；同目录 `record.json` 保存不可变元数据，SQLite 保存家庭、孩子、批次和回执关系。文件不会因分类或浏览而移动。临时上传进入 `temp/cloud-photos`，公开 APK 目录不包含任何云图。

云盘所有列表、原图和缩略图接口要求家庭鉴权。照片按当前孩子归属；下载仅通过授权请求，令牌不进入 URL。Android 下载限定本项目 HTTPS 路径、拒绝跳转，凭据不随系统文件选择活动持久化。

备份先取得 SQLite 快照，再复制对应的不可变云图，逐个核对大小和 SHA-256。后续快照可复用已核验的旧备份原件硬链接，不对线上原件建硬链接。缩略图可重建，不进入原件备份。

## 验证边界

本版验证使用合成照片：100 张文件选择和上传、101 张拒绝、丢回执与重启恢复、停止和失败重试、家庭/孩子隔离、原图下载哈希、多个原生相册批次收尾、窄屏布局，以及原生 Java 持久化和下载流检查。

浏览器原生桥模拟、Java 编译、单元测试和签名验证不等于物理 Android 设备验收。系统相册提供者行为、实际拍照、系统保存位置和后台切换仍需真机验证。当前只在应用前台主动上传，没有承诺系统后台持续传输、整盘自动同步、通用文档或 HEIC 支持。
