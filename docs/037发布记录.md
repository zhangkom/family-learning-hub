# 0.3.7 知识棱镜AI与学习闭环

## 已实现

- 名称统一为知识棱镜AI，versionCode 19；包名与长期签名保留。首页四格均连接已实现功能，知识星图当前提供知识点归类。
- 原题框选、按题选科、分析、人工校对之后可进入练习。原题校对入口移到题卡旁，空题干可明确采用识别文字再核对，支持补充知识点。
- 融会贯通从确认原题生成三道递进变式，使用第二次模型请求复核候选题。变式要求完整文字条件，拦下缺图引用与重复题，不生成未经验证的图示。
- 破茧成蝶记录卡点和已有尝试，围绕原题逐级提供三个提示；作答持久保存后排队批改，批改须引用真实提交文字。
- 答后可查看参考解法。完成当前练习可生成独立新题复测，记录是否参考提示/反馈，安排后续复测日期。已完成题目折叠再次作答区。
- 学习记录关联原题、题库、知识点、首页继续学习和各学生真实统计；原题后续修改不悄悄改变已生成练习。返回原题再回来保留同一组任务与草稿。
- 请求回执丢失不重复创建任务或作答；失败保留作答重试；队列有租约及过期结果隔离，重启恢复，家庭/学生隔离。
- 云盘原件仍保留原文件名，不设200张分组/应用层选图上限，同名由用户选择，分析与题图回看优先精确本机副本。

Windows 后端188项、Android客户端186项通过；类型、限定目录后端lint、客户端lint、两端构建通过。完整仓库lint原有问题未声称通过。

浏览器使用合成原片、合成原生桥和独立真实HTTP服务/worker，真实模型调用为0：收题→本机处理→上传→框题→分析核对→变式练习→错误反馈和提示→独立复测→原题返回→难题三级提示→复测→题库/知识点/档案统计→刷新续学→换学生隔离。模拟一次服务器已创建但回执丢失，重试仍仅一个会话。手机320/360/390及平板768宽度检查。模型输出校验与第二次复核调用另有单元测试。

云盘500张整批、5/500和200/500进度、回执丢失重试、中断续传、同名三选、本机原名、取消立即重选、原题图文卡和换学生隔离作回归。证据保存在工程work/qa-037及发布私有归档。

## 服务与发布约束

新增learning_sessions和learning_jobs两张表及索引，既有表和原件不迁移。发布前一致快照，候选版本用恢复副本启动，逐表验证既有数据保持且新表为空，再切换服务。日任务额度FAMILY_LEARNING_DAILY_LIMIT默认30，上限200；与识题额度分开，每次出题含生成与复核两个模型请求。AI停用时保留记录并暂停队列。
