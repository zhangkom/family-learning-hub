## 行为

App 未登录时先展示功能首页，点击个人功能后提示“注册”或“登录”。注册只填写账号和密码，不填写启用码；密码支持 6–128 字符，包括 6 位数字。旧长密码继续有效，家长网页登录及改密也使用相同范围。注册成功直接获得 Bearer 会话，重复账号给出中文错误并允许改名或转登录。

新普通家庭使用自己的账号 ID 作为 owner，不写入 `legacy_owners`，初始学生为空，由用户添加孩子。已有大小宝资料、扫描原件和文件路径均保留，未自动认领到新账号。旧启用码接口仍要求启用码且仅允许无账号时的首家庭开通；普通注册若先建立账号，也不会新增历史资料领取能力。

普通注册需 `FAMILY_REGISTRATION_ENABLED=true`。上线前确认 Nginx 覆盖 `X-Real-IP` 且应用仅监听 `127.0.0.1:3190` 后，才开启 `FAMILY_TRUST_PROXY=true`。注册限制为每来源 5 次/15 分钟、全局 30 次/15 分钟，与现有登录共享每账号 8 次/15 分钟的尝试限制；成功签发会话清除账号尝试计数。账号、密码散列及会话在同一事务处理，签发失败回滚账号。完整契约见 [Mobile API v1](mobile-api-v1.md)。

错题本、辅导、变式和学习报告仅作为标有“准备中”的入口展示，尚未完成对应闭环。未添加短信等权限，真机拍照和系统安装尚未验收，红米安装提示来源未定。
