# 学习方法四周版（2026-09-25）

## 本次交付

- 小宝：四周，每周3节数学、1节英语、1节地理，共20节。每天约15分钟，复习可以代替新课，不要求赶进度。
- 重点补弱：4节含字母绝对值、4节经纬度。另有8节数学基础和4节英语方法。
- 大宝：数学、物理、化学、生物各2节，共8节。每周从学校当前学习内容挑两个卡点，不视作深圳统一的高二教学进度。
- 每节4题：先试、同类、条件变式、隔时复习。合计112道原创题、28张配套练习页，保留原有12张专题练习页。
- 在线课、打印页和错题本使用同一个题号。学生版不显示答案，家长版显示答案、解析和出处；都可打印。

## 家庭使用方法

1. 小宝数学：把`|a|`比作“距离盒子”，先教`3|a|+2|a|=5|a|`；再取`a=-2`，让孩子发现`|a|`与`a`并不总相等。
2. 小宝地理：橘子瓣边比作经线，腰带比作纬线；再用E/W/N/S给快递地址写全，最后在交互网格上找宝箱。明确示意图的北上、东右约定，不把东经误当东半球。
3. 孩子先解释，再选答案；看提示后做对属于学习过程，不冒充独立完成。家长用“为什么”追问一句即可。
4. 在线答错自动入本；纸笔做完在批改台勾选真实错题再保存。纸笔错误也进入方法课复习提醒，未勾错不自动认定独立掌握。
5. 保留首次错误，后续作答另记历史。不同题独立答对两次后标记“独立完成”，到期再做对复习题后标记“隔时迁移通过”。后续间隔为2/7/30天的家庭规则，并非标准化测评。

## 边界与隐私

- 当前公开版不要求登录。错题和进度只保存在当前浏览器；Git同步的是代码，不会同步学习记录。换设备/换网址不会自动带过去。
- 扫描上传、云端同步、实时AI对话尚未在腾讯云公开版启用。本次没有为了免登录而开放孩子资料接口。
- 题目和示意图原创；外链是概念/备课参考，不是题目出处。未复制商业题库或嵌入需要额外商用许可的资源。
- 这是可继续产品化的四周版本，不是完整学年课程，也不代表已完成商业上线所需的家庭身份、数据隔离、支付与内容审校流程。

## 验证与维护

- `npm test`：学习状态、首次错误保护、纸笔反馈、题号唯一和配套目录完整性。
- `npx tsc --noEmit`：类型检查。
- `npm run build:self-hosted`：腾讯云独立构建。
- `node scripts/smoke-self-hosted.mjs http://127.0.0.1:3191`：12个入口、练习和资源完整响应、私有API拒绝伪造身份。
- `node scripts/test-study-browser.mjs`：真实Edge答题、错题历史、纸笔合流、交互地图、320/768/1024/1440宽度、打印和键盘焦点。
- `node scripts/test-study-print.mjs`：28页的学生/家长版本，共56个PDF均须为单页A4；学生页不泄露答案。
- 浏览器脚本默认连接本机3191端口；需要Playwright与Edge，可通过`PLAYWRIGHT_MODULE_PATH`指定已安装运行库。全量打印检查另需Poppler的`pdfinfo`以及安装了`pypdf`的Python（可用`PDF_PYTHON`指定）。
- 发布/回退流程见《腾讯云部署.md》，保留旧版本，不改动服务器其他站点。
