# 逐题与模块关联审核

日期：2026-10-03。本轮针对现有165条题目记录逐张查看题图，并检查161道已收录错题、200张原片、27份作业的来源关系。真实照片、账号标识、坐标清单及截图仅保存在工程私有审核目录，不进入源码和APK。

## 本轮发现与修复范围

| 链路 | 问题与处理 |
| --- | --- |
| 原页→单题 | 发现23项可修复裁图，包括22道新题遗漏的题设、图表或批注，以及1道旧题漏接的下一页选项。采用带校验值的私有人工审核清单修订派生图，原片、题目ID和收藏历史保留。旧题原照片自身缺字仍待补拍。 |
| 单题→阅读 | 定位摘要不能代替完整试卷题。摘要题仍展示完整真实题图；提供整张原片和关联续页入口，点击后读取匹配本机原片或明确选中的云端原片。 |
| 单题→模型 | 分别截取所需区域，长题按宽度可读的重叠片段完整传递；不再合并不相邻题框并把长图压成很小的一张。超过安全边界明确失败，不默默截断。 |
| 修图→本机缓存 | 图片身份包含SHA-256；即使字节长度不变，也不会复用旧缓存。版本不符自动恢复并持久保存，失败才显示重试。 |
| 修图→历史学习 | 学习快照绑定当时的题框和图像版本；早期无哈希记录通过保存的revision读原片。当前修图不改变过去练习看到的题。 |
| 确认→学习 | 检查父题、共用题干、图框和待补来源，返回具体阻断原因。定位摘要可结合完整真实题图解析，不宣称已完成文字转录。 |
| 错题→能力图谱 | 仅有定位摘要不能充当完整文字输入；需核对完整转录及图示条件。纸面红笔标记不能生成独立测验能力分，题图变化后的旧证据不冒充当前验证。 |
| 手机→电脑复核 | CLI/MCP读取全部图像片段后才记为完整读取；中途失败不能提交，已有授权范围、版本冲突检查和后台核对应用保留。 |
| 模块返回 | 待确认资料有筛选入口；题目详情返回保留上下文；已删除来源不跳到另一道题，历史记录说明原因。 |

## 数据修复约束

主机修复工具默认只验证。正式操作前需先在一致性备份副本应用同一清单，检查全部原件校验值、题目/收藏数量、无关表及修后成图。提交时再次校验管理员、学生、题目版本、任务状态和原页归属。修订图完整写入临时文件并同步后原子发布；重复清单按回执重放，失败不能留下已登记的半张图。

采用新图像版本后，运行版本必须保留版本读取支持。不能直接回退到不识别`image-revisions`的旧服务；回退应保留新读取层，或在暂停写入并核对新增业务数据后制定专门的数据恢复方案，不能盲目覆盖数据库。
