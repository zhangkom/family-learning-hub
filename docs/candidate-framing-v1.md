# 候选题框：客户端接入说明

2026-10-01 开发中，尚未进入已发布的 0.2.7。总线程3负责客户端，后台接口与独立设计验收分别由“大小宝名校计划”和“apk外观设计”负责。

## 使用行为

“自动找题”只请求几何候选，不请求模型解题。收到的框在原图上以虚线显示，初始不选中；原有题框保持只读。轻点可勾选或取消，调整模式可拖动和缩放。支持手动补框、上下/左右拆分、合并所选建议、删除与撤销。撤销记录最多保留20步，采用后清空，不能撤销已加入的正式题目。

“采用所选 N 个题框”要求明确选择新题科目，已有有效同图科目会预填。采用只新增本机待保存题目，未选建议仍可继续操作，已采用项不能重复采用。与现有题框大幅重叠时需要明确确认；不会自动合并旧题、复制旧作答或生成分析。“放弃本轮剩余建议”只丢弃未采用的临时建议。保存校对、存错题本、请求分析仍是后续独立操作。

## 接口与保护

`POST /scans/:id/candidate-regions` 请求 `{revision}`，直接返回 `scanId/revision/algorithm/coordinateSpace/image/status/candidates/warnings`，没有 `scan` 包装。`coordinateSpace` 必须为 `oriented-normalized`，图片尺寸必须与当前浏览器已显示图片的正向尺寸一致；坐标为0到1，候选最多24个，不能为零面积或越界。建议采用全新题目和区域UUID，本页总题数仍受100题限制。

明确取消、离开照片、切换归属后的迟到响应会被丢弃。同页用户修改题框或修订号变化时不会应用旧响应。409使用现有草稿冲突恢复；空候选、服务忙、未启用接口、超时和尺寸不匹配均保留手动框题。没有可信坐标时不画示意框。

当前基于上传图的正向坐标。未来若上传的是用户确认的处理件，题框属于该处理件；回溯本机相机原片需使用对应处理版本的逆矩阵，不能混用两种坐标。用户已明确原片可留手机、确认处理件上传；当前版本尚未接入该预处理流程。

- `scripts/verify-candidates.mjs`：合成接口、真实CDP触摸勾选和44px手柄、拆分/删除/合并与撤销、分批采用防重复、重叠确认、异常退路、取消/编辑/离页后的迟到响应、409草稿保护、320/360/390/768px无横向溢出。记录10次候选请求，0次模型分析请求。
- 原有 `verify-framing.mjs`、`verify-photo-subject.mjs` 已回归通过。

上述是合成客户端检查，不代表几何算法的真实试卷准确率、真实后台接口联调或安卓真机验收；待后台提交与独立设计验收后继续收口。
