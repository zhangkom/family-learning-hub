# 腾讯云部署

访问地址： https://123.207.232.151/family-learning/

2026-10 私有同步版提供家庭账号、跨设备记录、扫描上传与逐题核对、DeepSeek 图片识题、家长复盘。未登录仍可使用本机练习。

2026-09-25 线上版本存在 GitHub 未包含的扫描功能；首次家庭账号绑定旧 `family` 原件目录，旧扫描默认归大宝，已确认错题自动进入同步记录。

## 构建与检查

```sh
npm ci
npm test
npx tsc --noEmit
npm run build:self-hosted
```

构建使用当前锁定的 vinext 独立 Node 输出，生成 `dist/standalone`。
本地运行：将 `HOST=127.0.0.1`、`PORT=3190`、`NODE_ENV=production` 设置到运行环境，再执行 `npm run start:self-hosted`。
运行 `node scripts/smoke-self-hosted.mjs http://127.0.0.1:3190` 验证页面、练习、静态资源和受保护接口。
普通 `npm run build` 保留 Sites 构建方式。

`node scripts/verify-family.mjs` 会在两个浏览器和两个临时服务器中验证登录、断网补传、扫描与错题、备份导入、退出隔离、完整备份还原及原有学习流程。需要 Playwright / Edge；可用 `PLAYWRIGHT_MODULE_PATH` 指定现有运行时。测试目录位于忽略的 `work/`，截图位于 `outputs/`。默认不调用收费模型；仅在设置测试专用的 `FAMILY_TEST_AI=1` 与模型环境变量时，用合成题图片测试实际识题。

## 私有配置

原配置 `/etc/family-learning-hub.env` 保留，以便旧版本回退。新增 `/etc/family-learning-sync.env`（root:root，0600），由 `deploy/private-sync.conf` 作为 systemd drop-in 加载。配置值不能进入仓库、构建产物或前端：

| 变量 | 用途 |
| --- | --- |
| `FAMILY_DATA_DIR` | `/var/lib/family-learning-hub`，原件和 SQLite 私有目录 |
| `FAMILY_PUBLIC_ORIGIN` | `https://123.207.232.151`，精确校验写请求来源 |
| `FAMILY_SETUP_TOKEN` | 随机 32 字节以上的首次启用码；仅首次创建账号使用 |
| `FAMILY_AI_API_KEY` | 服务器侧模型密钥 |
| `FAMILY_AI_BASE_URL` | DeepSeek 为 `https://api.deepseek.com` |
| `FAMILY_AI_MODEL` | `deepseek-flash`，支持图片输入 |
| `FAMILY_AI_PROTOCOL` | `chat-completions`；适配层也支持 `responses` |
| `FAMILY_AI_JSON_MODE` | DeepSeek 使用 `json_object` |
| `FAMILY_AI_DAILY_LIMIT` | 每家庭每个 24 小时窗口最多识题次数，默认 10，上限 50 |

依据：[DeepSeek 图像输入](https://api-docs.deepseek.com/guides/vision/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。DeepSeek 当前不接收 PDF 文件输入，本版不会把 PDF 当图片请求发送；原 PDF 仍可上传、查看和手动整理。

密码采用 scrypt，数据库只保存会话令牌哈希；Cookie 为 HttpOnly / Secure / SameSite=Strict。首次只允许创建一个家庭账号。扫描最大 8 MB，总空间 500 MB，回收站文件仍计入空间；修改带版本号，避免两台设备覆盖彼此编辑。

## 服务器布局

- `/home/ubuntu/codex_project/workspace_own/family-learning-hub/`：完整开发项目，包含源码、Git 历史、文档、脚本及可重新安装的依赖锁文件。分支为 `codex/family-private-sync`。
- 开发目录中的 `work/handoff/`：源码 Git bundle、迁移清单与当次线上构建归档；`outputs/` 为合成测试的验证截图和 PDF。

- `/opt/family-learning-hub/releases/<版本>/`：独立构建产物，不含凭据或源站学习记录。
- `/opt/family-learning-hub/current`：当前版本软链接。
- `/etc/systemd/system/family-learning-hub.service`：开机自启、故障重启和资源限制。
- `/etc/nginx/snippets/family-learning-location.conf`：HTTPS 服务中的独立路径。
- Node 仅监听 `127.0.0.1:3190`，外网通过现有 443 端口访问。

在服务器继续开发：

```sh
cd /home/ubuntu/codex_project/workspace_own/family-learning-hub
git status --short --branch
npm ci --no-audit --no-fund
npm test
npx tsc --noEmit
npm run build:self-hosted
```

开发目录和线上运行目录分开，源码更新不会自动替换线上版本。Windows 本机保留一份副本，作为迁移核对和恢复用途。

服务器已有其他网站。仅在既有 HTTPS server 块加入：

```nginx
include /etc/nginx/snippets/family-learning-location.conf;
```

配置模板在 `deploy/`。修改 Nginx 前备份，执行 `nginx -t` 成功后再 reload。
证书由服务器现有续期任务管理；本项目不另设证书和防火墙入口。

## 更新与回退

1. Git 拉取确认后的提交，在开发电脑构建并通过检查。
2. 将 `dist/standalone/` 打包，经 SSH 上传新版本目录。
3. 在备用回环端口启动候选版本，运行 smoke 脚本。
4. 将 `current` 指向已验证版本，重启 `family-learning-hub`。
5. 对公网 HTTPS 地址运行同一 smoke 脚本，并检查其他已有网站仍可访问。

失败时将 `current` 恢复到上一版本，重启服务即可；不要删除旧版本或覆盖其他网站的配置。
连接信息仅从私人服务器配置文档读取，密码、密钥和文档副本均不提交 Git。

运行日志：`sudo journalctl -u family-learning-hub -n 100 --no-pager`。
服务状态：`sudo systemctl status family-learning-hub --no-pager`。

## 完整备份与恢复

安装 `deploy/family-learning-backup.service` 和 `.timer` 后启用定时器。每天北京时间 03:30 附近备份；首次部署也应立即执行一次。快照在私有目录 `backups/family-<时间>/`，包括 SQLite、扫描原件、记录 JSON 和 SHA-256 清单，保留最近 30 份。原件不可变，元数据原子写入；在线快照可能略早于同一时刻的新上传，跨文件不构成单一事务。重要更新前短暂停止本应用并额外做完整归档，确保一致。

恢复前停止本应用并备份现状，在**新的目录**校验 `manifest.json` 所有文件哈希和 SQLite `PRAGMA integrity_check`。恢复数据库及哈希命名的原件目录，移除恢复目标中旧数据库的 `-wal` / `-shm`（不能对运行中的数据库操作）。按原权限交由 `family-learning-hub` 的 StateDirectory 使用后重启。配置文件单独安全备份，不从 Git 恢复。运行临时独立实例验证账号、同步记录与原件，再切换生产目录。当前没有永久删除扫描的用户入口。

依据：[vinext 独立部署说明](https://github.com/cloudflare/vinext#standalone-output)。
