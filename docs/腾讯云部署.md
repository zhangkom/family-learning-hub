# 腾讯云部署

访问地址： https://123.207.232.151/family-learning/

本次是当前公开版迁移：学习计划、原创练习、打印和浏览器本地错题可用。原 Sites 地址保留。
错题、练习进度仍保存在浏览器；新旧地址属于不同来源，因此不会自动带过旧地址的本地记录。
扫描上传和跨设备同步仍未开放，界面有明确提示。服务器不信任客户端传入的 Sites 身份头。
日后应一起实现家庭身份验证和私有存储，再启用云端接口；不要通过伪造固定身份来跳过验证。

## 构建与检查

```sh
npm ci
npm test
npm run build:self-hosted
```

构建使用当前锁定的 vinext 独立 Node 输出，生成 `dist/standalone`。
本地运行：将 `HOST=127.0.0.1`、`PORT=3190`、`NODE_ENV=production` 设置到运行环境，再执行 `npm run start:self-hosted`。
运行 `node scripts/smoke-self-hosted.mjs http://127.0.0.1:3190` 验证页面、练习、静态资源和受保护接口。
普通 `npm run build` 保留 Sites 构建方式。

## 服务器布局

- `/opt/family-learning-hub/releases/<版本>/`：独立构建产物，不含凭据或源站学习记录。
- `/opt/family-learning-hub/current`：当前版本软链接。
- `/etc/systemd/system/family-learning-hub.service`：开机自启、故障重启和资源限制。
- `/etc/nginx/snippets/family-learning-location.conf`：HTTPS 服务中的独立路径。
- Node 仅监听 `127.0.0.1:3190`，外网通过现有 443 端口访问。

服务器已有其他网站。仅在既有 HTTPS server 块加入：

```nginx
include /etc/nginx/snippets/family-learning-location.conf;
```

配置模板在 `deploy/`。修改 Nginx 前备份，执行 `nginx -t` 成功后再 reload。
证书由服务器现有续期任务管理；本项目不另设证书和防火墙入口。

## 更新与回退

1. Git 拉取确认后的提交，在开发电脑构建并通过检查。
2. 将 `dist/standalone/` 打包，经 SSH 上传新版本目录。
3. 在备用回环端口启动候选版本，运行 smoke 脚本。
4. 将 `current` 指向已验证版本，重启 `family-learning-hub`。
5. 对公网 HTTPS 地址运行同一 smoke 脚本，并检查其他已有网站仍可访问。

失败时将 `current` 恢复到上一版本，重启服务即可；不要删除旧版本或覆盖其他网站的配置。
连接信息仅从私人服务器配置文档读取，密码、密钥和文档副本均不提交 Git。

运行日志：`sudo journalctl -u family-learning-hub -n 100 --no-pager`。
服务状态：`sudo systemctl status family-learning-hub --no-pager`。

依据：[vinext 独立部署说明](https://github.com/cloudflare/vinext#standalone-output)。
